# Articles

このセクションでは、デジタルアイデンティティ領域の個別トピック解説や時事ニュース、動向まとめを掲載しています。

Spec セクションが技術仕様そのものを扱うのに対し、Articles セクションは以下のようなコンテンツを扱います。

- **トピック解説**: 特定の概念 (例: パスキー、SSI、Verifiable Credentials) を横断的に解説
- **時事ニュース**: ID 領域の重要なアップデートや業界動向
- **比較・考察**: 複数仕様・製品の比較や、設計上のトレードオフについての議論

個別の記事は、左サイドバー (または上部ナビゲーションの **Articles**) から参照してください。新しい順に並んでいます。

> 新しい Article を追加したいときは、`/article` スキルを使用してください。
