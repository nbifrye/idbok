# Articles

デジタルアイデンティティ領域の個別トピック解説、時事ニュース、比較・考察を掲載するセクションです。Spec セクションが技術仕様そのものを扱うのに対し、Articles セクションはトピック横断の解説や、製品・実装・標準化の動向など、時間軸を持ったコンテンツを扱います。

想定する記事タイプ:

- **トピック解説**: 特定の概念 (例: パスキー、SSI、Verifiable Credentials) を横断的に整理する記事
- **時事ニュース**: ID 領域の重要なアップデート・リリース・規制動向
- **比較・考察**: 複数仕様・製品・アプローチの比較や、設計上のトレードオフの議論

サイドバーには公開日の新しい順に記事が並びます。
