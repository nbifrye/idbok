# OpenID Foundation Ecosystem Support CG 活動レポート (2026年3月)

> 執筆日: 2026-04-16（遡及執筆）

## 1. 概要

**Ecosystem Support CG (ESCG)** は、OpenID Foundation が展開するエコシステム全体の支援活動を担うコミュニティグループである。Open Banking / オープンファイナンス領域の実装者や規制当局との連携促進、OIDF 加盟組織へのアウトリーチ、各国・地域での OIDF 認定プログラムの普及支援などを主な活動領域とする。仕様策定そのものはスコープ外とし、エコシステムごとの実装ベストプラクティスや「Open Banking Reference Technical Architecture and Best Practices」のようなガイダンス文書の整備、エコシステム間の経験共有を主眼とする。共同チェアは Dima Postnikov、Ralph Bragg、Mark Verstege の3名が務め、月次ミーティングを EU 時間帯と Pacific 時間帯で交互に開催している。

2026年3月の活動について、公開されているメーリングリストアーカイブ・GitHub リポジトリ・openid.net ブログの各情報源を調査したが、**公開された記録を確認することはできなかった**。このCGは議事録が非公開であり、メーリングリストへの投稿も主に会議前アジェンダ通知に限定される運用スタイルをとっている。以下、調査した情報源ごとに結果を記録する。

## 2. 公開された仕様・ドラフト改訂

該当月に ESCG が直接関与する仕様公開・パブリックレビュー開始の告知は、openid.net ブログ・ニュースにおいて確認できなかった。

## 3. ミーティングおよびメーリングリスト・GitHub 上の公開記録

### ミーティング

ESCG は月次ミーティングを概ね4週間ごとに EU 時間帯（月曜 18:00 Sydney 時間）と Pacific 時間帯（金曜 10:00 Sydney 時間）で交互に開催している。2026年4月のカレンダーから逆算すると、2026年3月にも同様のペースで2回程度の会議が開催されたと推定されるが、議事録は non-public であるため内容は確認できない。

標準アジェンダとして把握できているのは（2025年9月のメーリングリスト投稿より）:

1. 新参加者の紹介
2. CG 管理業務
3. イベント情報
4. エコシステム更新情報
5. OIDF メンバーシップリマインダー
6. 一般ディスカッション（アクション、チャーターレビュー、Open Banking Technical Reference Architecture、バックログ）
7. AOB（その他事項）

### メーリングリスト

公開アーカイブ（https://lists.openid.net/pipermail/openid-ecosystem-support/）の月次インデックスを確認したところ、**2026年3月分のアーカイブは存在しない**。確認できた最新のアーカイブは 2025年9月である。

このメーリングリストは「private list」であり、メンバー以外にはメンバーリストが公開されない旨が listinfo ページに明記されている。公開アーカイブに残る投稿は会議前アジェンダ通知が中心であり、実質的な議論はミーティング内で行われていると考えられる。

### GitHub

GitHub リポジトリ（https://github.com/openid/cg-ecosystem-support）は 2025年1月2日に作成されたが、2026年3月時点においてもコンテンツは一切追加されておらず、Issue・Pull Request ともに 0 件のままである。リポジトリの最終 push 日は作成日（2025年1月2日）から変化がない。

## 4. 関連イベント

該当月に ESCG が直接関与したイベント情報は確認できなかった。

なお、2026年3月末に **iGov WG** 関連の Implementer's Draft 承認投票（投票期間: 2026年3月29日〜4月12日）が openid.net に告知されているが、これは ESCG の活動ではない。

## 5. 今後の予定（2026年3月末時点）

該当月完了時点の公開情報から、次の活動が予定されていたと推定される:

- 4月の月次ミーティング（EU 会議: 4月13日頃、Pacific 会議: 4月23日頃）
- OIDF グローバルイベント（2026年後半開催予定）に関するアンケートやアウトリーチ活動の継続
