# Specs

このセクションでは、デジタルアイデンティティ領域の技術仕様 (RFC、OpenID 仕様、W3C 勧告、FIDO 仕様など) を 1 仕様 = 1 記事 で解説します。

各記事は、仕様の背景・主要概念・プロトコルフロー・セキュリティ考慮事項・関連仕様をまとめた Body of Knowledge として整備されています。

個別の記事は、左サイドバー (または上部ナビゲーションの **Specs**) から参照してください。

## カバー対象の例

- **IETF**: OAuth 2.0 ファミリ (RFC6749, RFC6750, RFC7636 など)、JOSE (RFC7515–7519)、Token Exchange (RFC8693) ほか
- **OpenID Foundation**: OpenID Connect Core, FAPI, CIBA ほか
- **W3C**: Verifiable Credentials, DID, WebAuthn ほか
- **FIDO Alliance**: CTAP, Passkey 関連ガイドライン ほか

> 新しい Spec 記事を追加したいときは、`/spec` スキルを使用してください。
