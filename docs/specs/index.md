# 仕様解説

デジタルアイデンティティに関する技術仕様の解説記事です。RFC等の具体的な技術仕様を、一つの仕様につき一つの記事で解説します。

## 対象分野

- **OAuth 2.0 / 2.1** - 認可フレームワークとその拡張仕様
- **OpenID Connect** - 認証レイヤーの仕様群
- **JOSE** - JWT、JWS、JWE等の暗号・署名関連仕様
- **FIDO / WebAuthn** - パスワードレス認証の仕様
- **Verifiable Credentials / DID** - 分散型アイデンティティ関連仕様
- **SAML** - エンタープライズ向けフェデレーション仕様
- **SCIM** - アイデンティティプロビジョニング仕様
