# Specs

デジタルアイデンティティ領域の技術仕様を、**1 仕様 = 1 記事** の形式で解説するセクションです。対象は RFC, OpenID 仕様, W3C 勧告, FIDO 仕様 などの公式ドキュメントで、それぞれの背景・主要概念・プロトコルフロー・セキュリティ考慮事項・関連仕様を整理することを目指しています。

個別の記事はサイドバー (または上部ナビゲーションの **Specs**) から参照してください。

## 主なカバー範囲

- **IETF**: OAuth 2.0 ファミリ、JOSE (JWS / JWE / JWK / JWT)、Token Exchange ほか
- **OpenID Foundation**: OpenID Connect Core, FAPI, CIBA ほか
- **W3C**: Verifiable Credentials, Decentralized Identifiers (DID), WebAuthn ほか
- **FIDO Alliance**: CTAP, Passkey 関連ガイドライン ほか
