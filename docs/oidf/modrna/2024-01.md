# OpenID Foundation MODRNA WG 活動レポート (2024年1月)

> 執筆日: 2026-05-22（遡及執筆）。本記事は 2024 年 1 月の MODRNA WG 活動を、約 2 年 4 ヶ月後の視点から `openid-specs-mobile-profile` メーリングリストの公開アーカイブ、`openid.net` 上の公開情報、および同月開催の OpenID Summit Tokyo 2024 などの業界イベント記録をもとに再構成したものである。MODRNA WG の議事録は non-public 運用のため、コール内の詳細議論は公開チャネル上には残っておらず、本記事は ML 公開アーカイブから読み取れる範囲の運用記録の整理を主としている。

## 1. 概要

MODRNA (Mobile Operator Discovery, Registration, & autheNticAtion) WG は、モバイルネットワークオペレータ (MNO) が OpenID Connect / OAuth 2.0 をベースに GSMA Mobile Connect 互換のアイデンティティサービスを提供するための相互運用プロファイルを策定する OpenID Foundation のワーキンググループである。共同議長は Bjorn Hjelm と John Bradley (Yubico) の 2 名、定例コールは隔週火曜 14:00-15:00 UTC（北米太平洋時間 7:00-8:00、中央欧州時間 15:00-16:00）のカデンスで運営され、議事録は non-public、仕様ソースは `bitbucket.org/openid/mobile/src/master/` で管理されている（`github.com/openid/` 配下に MODRNA WG の公式リポジトリは存在しない）。WG ページ ([openid.net/wg/modrna/](https://openid.net/wg/modrna/)) は GSMA との Mobile Connect / RCS / Automotive Identity (AiD) 領域での協業、および 3GPP との 5G IAM アーキテクチャ・Mission Critical Services に関する標準化協力を WG のスコープとして明示している。

2024 年 1 月の MODRNA WG は、月内 ML 投稿合計 **5 通** で構成された比較的静かな月であった。`openid-specs-mobile-profile` の公開アーカイブで本月にエントリ HTML が実体として生成されている週は以下の 3 週で、それ以外の週（Week-of-Mon-20240115、Week-of-Mon-20240122）は親インデックス上にリンクが残っているものの本文 HTML は 404 を返す（実質的な投稿ゼロ週）。

隔週火曜カデンス上、本月の定例コール候補日は **1 月 2 日 (火) と 1 月 16 日 (火) と 1 月 30 日 (火)** の 3 回である。1 月 2 日は新年休暇直後で議長 Bjorn Hjelm により事前キャンセル（後述）、1 月 16 日は ML 上にアジェンダ・キャンセル通知のいずれも存在せず、1 月 30 日は Hjelm によるアジェンダ ML 投稿が確認できる定例開催日である。

本月の最大の特徴は、**1 月 11 日に共同議長 Bjorn Hjelm 自身が Bitbucket 上で 2 件の Issue（#216 / #217）を起票し、その自動通知が ML に配信された**点である。これは 2024 年通年で MODRNA WG ML に持ち込まれた合計 3 件の具体的技術 Issue 起票（後の 2/28 Heenan Issue #218 を含む）のうちの先行する 2 件であり、本月の MODRNA WG が編集タスクの棚卸しを進めていたことを示す数少ない可視のシグナルとなっている。Issue #216 は OpenID Foundation 仕様の "naming conventions" 整合化（過去版へのリンク追加）、Issue #217 は MODRNA Authentication Profile を ACR profile ドラフト仕様の最新変更に追随させる、という編集系の 2 件であり、いずれも仕様本文の技術的論点というよりは編集規約・整合性維持の領域に属する。

さらに 1 月 30 日には、議事録 non-public 下では珍しく **アジェンダ本文 ML 投稿** が確認できる（[001951.html](https://lists.openid.net/pipermail/openid-specs-mobile-profile/Week-of-Mon-20240129/001951.html)）。このアジェンダは標準 8 項目テンプレート（Roll Call / Adoption of the Agenda / External Organizations / Events / Specification Status / OpenID Certification for MODRNA / Issue Tracker / AOB）に Events 4 件（IETF 119 Brisbane Mar. 16-24 ／ OpenID Foundation Workshop Apr. 15 ／ IIW Apr. 16-18 ／ IETF 120 Vancouver Jul. 20-26）を組み合わせた構成で、後の 2/27 アジェンダで External Organizations セクションに細目（GSMA / CAMARA Project / FAPI Presentation / eKYC-IDA Presentation 等）が明示列挙される直前の **細目なし版** に相当する。本 1/30 アジェンダの External Organizations 項目は細目を持たず単なる見出し行のみで、CAMARA や eKYC-IDA への具体的言及は本月時点ではアジェンダ上に登場しない。

本月の MODRNA 仕様群に関する新規ドラフト改訂・パブリックレビュー・Notice of Vote のアナウンスは ML・`openid.net/tag/modrna/` のいずれにも存在しない。月内に開催された OpenID Summit Tokyo 2024（1/19、渋谷）について、MODRNA WG ML 上での言及・クロスポストは観測されない。

### Issue #216（過去版リンク追加）の起票

2024-01-11 19:43:04 UTC、共同議長 Bjorn Hjelm が Bitbucket 上で起票した本 Issue は、OpenID Foundation 仕様の **編集規約整合化** を目的とする。本文の論旨は以下のとおり。

- **論点**: OpenID Foundation の最新の編集ガイドライン（naming conventions）では、仕様ドキュメントの "Introduction" セクションに過去のドラフト版へのリンクを含めることが求められる
- **参照モデル**: OpenID Connect Core 1.0 の Introduction セクションが推奨実装例として参照される
- **対象作業**: MODRNA WG が保守する各仕様ドキュメントの Introduction セクションに、過去版へのリンクを追加する編集作業を実施する

これは仕様本文の技術的論点ではなく、Foundation 全体としてのドキュメント編集規約の整合化に属する作業項目である。OIDF が 2023 年後半から進めていた仕様編集規約の標準化（OpenID Connect Core 1.0 を編集スタイルガイドの参照モデルとする方向性）の MODRNA WG への波及である。

### Issue #217（Authentication Profile の ACR profile ドラフト追随）の起票

2024-01-11 19:50:43 UTC（Issue #216 の起票から 7 分後）、Hjelm が Bitbucket 上で続けて起票した本 Issue は、MODRNA Authentication Profile の本文を **ACR profile draft spec の最新版変更点に追随させる** ことを目的とする。

- **論点**: 新しい "(minimum interoperability) ACR profile spec" ドラフトの変更点が MODRNA Authentication Profile に影響を与える可能性がある
- **対象作業**: MODRNA Authentication Profile を、新 ACR profile draft の影響を受ける箇所について更新する
- **進捗状態**: 起票時点で具体的な編集差分は提示されていない。WG コール内での討議と編集担当の割り当てが今後の作業となる

「ACR profile spec」が指すドキュメントは投稿本文中で明示されていない。MODRNA Authentication Profile 自体が `acr` クレームの利用方法を規定する仕様であることを踏まえると、Foundation 横断で議論されていた最小相互運用性向けの ACR 値ガイドライン草案（Mike Jones らを中心に AB/Connect WG で並行整理されていた領域）との整合化を念頭に置いた起票である可能性が高いが、本投稿のみから ACR profile draft spec の正体を確定することはできない。

両 Issue（#216・#217）とも、起票時点で具体的な解決方針・編集担当・期限の指定はなく、Bitbucket 上での Issue Tracker への登録のみが行われている。本月の MODRNA WG が編集規約・他仕様追随の双方で **棚卸し系の整理作業** を進めていた様子が読み取れる。

### 推定される 1/30 コール内議題

議事録 non-public 運用下では、1/30 コール内の具体的議論を公開チャネルから直接確認することはできない。ただし、本月の ML 上の動きから推定される議題は以下のとおりである。

- **Issue Tracker**: 1/11 に起票された Issue #216（過去版リンク追加）と Issue #217（ACR profile draft 追随）の 2 件が新規 Issue として議題候補となる。両 Issue とも編集系のタスクで、編集担当の割り当てとスケジュール調整が議題となった可能性が高い
- **External Organizations**: アジェンダ上は細目なしのため、GSMA との恒常的調整（Mobile Connect / RCS / AiD）が口頭で報告される標準パターンに従ったと推定される
- **Events**: IETF 119 Brisbane（3/16-24）が約 7 週間後に控えており、MODRNA WG コアメンバーの参加調整が話題となった可能性がある。4 月の OIDF Workshop と IIW XXXVIII（共に Mountain View / Sunnyvale 圏で連続開催）も準備期間に入る
- **Specification Status**: 主要仕様群（CIBA Core / MODRNA Authentication Profile / Account Porting / User Questioning API / Discovery / Registration）の現状リスト確認のみで、次版改訂計画の具体的アナウンスは本月時点ではない

これらアジェンダ項目のうち、Issue Tracker サブ項目は 2 月末の Heenan Issue #218 (CIBA Errata) 起票と 3 月以降の WG コール内討議に発展していく（[2024 年 2 月レポート](./2024-02.md) §2、[2024 年 3 月レポート](./2024-03.md) §2 参照）。

## 5. GitHub 上の議論

MODRNA WG の仕様ソースは GitHub ではなく Bitbucket Cloud (`bitbucket.org/openid/mobile/src/master/`) で管理されている。GitHub 側に MODRNA WG の公式一次リポジトリは存在しない（`github.com/openid/MODRNA` といった誤記が一部で見られるが、そのようなリポジトリは現存しない）。

Bitbucket Cloud は SPA 描画のため外部からのクローリングに適さず、本稿の調査範囲では 1 月中の Bitbucket Issue / PR / コミット活動の網羅的件数を確認できない。ただし、(i) 1/11 に Bjorn Hjelm が起票した Issue #216 (Update specs with link to previous versions) と Issue #217 (Update Authentication Profile with any changes to ACR profile draft spec) の 2 件は ML 自動通知から起票事実が確認できる、(ii) これら 2 件は本月のうちに **クローズされたとは確認できず**、後の月のアジェンダの Issue Tracker サブ項目に継承されていく見込み、(iii) MODRNA WG の ML 上で 1 月中に Bitbucket 由来の自動通知メールは上記 2 件以外には届いていない、(iv) 1/30 アジェンダの "Specification Status" 項目が項目見出しのみで具体的な版番号更新計画を欠くこと、から、Bitbucket 上でも本月は新規 Issue 2 件の起票以外には目立った動作はなかったと推定できる。

FAPI WG 側の Bitbucket Issue [#630 (Android Carrier OpenID API)](https://bitbucket.org/openid/fapi/issues/630/android-carrier-openid-api) と [#632 (Security profile for CAMARA)](https://bitbucket.org/openid/fapi/issues/632/security-profile-for-camara) は、後の 2/27 MODRNA アジェンダで External Organizations 参照リンクとして含まれることになる Issue 群だが、本月の 1/30 MODRNA アジェンダには細目が登場しないため、本月時点での MODRNA WG コール内での議論状況は公開チャネルからは確認できない。

なお、Atlassian による Bitbucket Cloud Issues / Wiki の 2026-08-20 完全廃止アナウンスは本時点（2024 年 1 月）では未公表（2026 年 3 月公表）であり、MODRNA WG として Issue Tracker 代替候補を検討する動きは本月の公開チャネルには存在しない。

## 7. 今後の予定（2024 年 1 月末時点の視点）

1 月末時点の公開情報からは、MODRNA WG の 2 月以降の明示的な予定は ML・`openid.net` いずれにも掲載されていない。隔週カデンスと月内事象から推定される事項は以下のとおり。

- **定例コール**: 隔週火曜サイクル（1/2 キャンセル、1/16 公開記録なし、1/30 開催）に従えば、2 月の候補日は 2 月 13 日（火）と 2 月 27 日（火）の 2 回 — 実際に 2/13 は議長欠席で事実上のサイレント、2/27 は External Organizations 細目を最大限明示した詳細版アジェンダで開催される（[2024 年 2 月レポート](./2024-02.md) 参照）
- **Issue #216 / #217 の編集作業**: 1/11 起票直後で、2 月コール内の Issue Tracker 議題で編集担当の割り当てと作業スケジュール調整への持ち越しが見込まれる。本月の起票後、これら編集系 Issue がいつクローズされるかは本月時点では未確定
- **CAMARA Project 連携の継続（推定）**: Bitbucket Issue #215 (Android Carrier OpenID API)、FAPI Issue #630・#632 (Security profile for CAMARA) の各 Issue は本月時点でいずれもオープン状態を維持していたと見られる。本月の 1/30 アジェンダには細目として登場しないが、2/27 アジェンダで External Organizations / CAMARA Project サブ項目として明示列挙される伏線となる
- **OpenID Foundation Workshop（4/15）会場の確定**: 本月時点では未確定で、2 月以降のアジェンダで Sunnyvale (Google) が明示されていくと予想される
- **IETF 119 Brisbane（3/16-24）**: 北米・欧州・豪州 IAM 関係者の主要関心事項。MODRNA WG コアメンバー（Bjorn Hjelm / John Bradley 等）の現地参加は通例
- **Implementer's Draft 群の現状維持**: MODRNA Authentication Profile ID1 / Account Porting ID1 / User Questioning API ID2 はいずれも次版改訂の公式アナウンスがなく、現行ステータスを維持
- **OpenID Foundation 2024 年理事会選挙の結果反映**: 1/16 PST 正午締切の理事会選挙結果は本月末以前に確定するが、MODRNA WG ML 上での結果共有・新理事の MODRNA WG 内での役割言及は本月時点では未着

1 月の対外可視な活動は (i) 議長 1 名による 1/2 新年休暇直後コールキャンセル通知 1 通、(ii) Foundation 全体宛の理事会選挙アナウンスの WG ML 一斉配信 1 通、(iii) 議長 1 名による 1/11 編集系 Issue #216 / #217 起票 ML 自動通知 2 通、(iv) 議長 1 名による 1/30 コール用アジェンダ ML 投稿 1 通（External Organizations 細目なしの簡素版）、の 4 種類合計 5 通に集約される。当時の読者にとっては「OpenID Summit Tokyo 2024 開催月でありながら MODRNA ML 上では編集系 Issue 起票 2 件と運用通知 3 件の静粛な月」として記憶される月であり、後の月から振り返ると、本月は 2024 年通年で **MODRNA Authentication Profile の編集タスク棚卸し（Issue #216 / #217 の起票）が ML 公開チャネルに姿を見せた最初の月** として位置づけられる。
