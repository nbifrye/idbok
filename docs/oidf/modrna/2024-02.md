# OpenID Foundation MODRNA WG 活動レポート (2024年2月)

> 執筆日: 2026-05-22（遡及執筆）。本記事は 2024 年 2 月の MODRNA WG 活動を、約 2 年 3 ヶ月後の視点から `openid-specs-mobile-profile` メーリングリストの公開アーカイブ、`openid.net` 上の公開情報、および同月開催の MWC Barcelona 2024 などの業界イベント記録をもとに再構成したものである。MODRNA WG の議事録は non-public 運用のため、コール内の詳細議論は公開チャネル上には残っておらず、本記事は ML 公開アーカイブから読み取れる範囲の運用記録の整理を主としている。

## 1. 概要

MODRNA (Mobile Operator Discovery, Registration, & autheNticAtion) WG は、モバイルネットワークオペレータ (MNO) が OpenID Connect / OAuth 2.0 をベースに GSMA Mobile Connect 互換のアイデンティティサービスを提供するための相互運用プロファイルを策定する OpenID Foundation のワーキンググループである。共同議長は Bjorn Hjelm と John Bradley (Yubico) の 2 名、定例コールは隔週火曜 14:00-15:00 UTC（北米太平洋時間 7:00-8:00、中央欧州時間 15:00-16:00）のカデンスで運営され、議事録は non-public、仕様ソースは `bitbucket.org/openid/mobile/src/master/` で管理されている（`github.com/openid/` 配下に MODRNA WG の公式リポジトリは存在しない）。WG ページ ([openid.net/wg/modrna/](https://openid.net/wg/modrna/)) は GSMA との Mobile Connect / RCS / Automotive Identity (AiD) 領域での協業、および 3GPP との 5G IAM アーキテクチャ・Mission Critical Services に関する標準化協力を WG のスコープとして明示している。

2024 年 2 月の MODRNA WG は、月内 ML 投稿合計 **3 通** で構成された比較的静かな月であった。`openid-specs-mobile-profile` の公開アーカイブで本月にエントリが生成された週は以下の 2 週で、それ以外の週次インデックス HTML（Week-of-Mon-20240129、Week-of-Mon-20240205、Week-of-Mon-20240219）は存在しない（投稿ゼロ週）。

### Issue #218（CIBA Errata 候補）の起票

2/28 21:13:00 UTC、Joseph Heenan が "Issue #218: Overstrict requirements on invalid_client error being http 401" 件名で起票した本 Issue は、本月の MODRNA WG にとって **唯一の月内に登場した具体的 technical issue** である。本文の論旨は以下のとおり。

- **論点**: CIBA Core 1.0 Final（2021-09 公開）§13 が `invalid_client` エラー応答に対し HTTP 401 ステータスコードを義務付けている
- **問題**: HTTP 401 応答は `WWW-Authenticate` ヘッダ同梱を要求するが、CIBA のクライアント認証方式は全てが challenge-response 型ではなく（例: `client_secret_post`、`private_key_jwt`、`tls_client_auth` 等）、`WWW-Authenticate` を意味的に発行できないケースが存在する
- **参照根拠**: RFC 6749 §5.2（OAuth 2.0 token endpoint のエラー応答）は HTTP 400 または HTTP 401 のいずれかを許容しており、CIBA Core も同様の柔軟性を持つべきである
- **提案**: CIBA Core §13 を Errata として緩和し、HTTP 400 / 401 のいずれも許容する

Heenan は Authlete に在籍し OpenID Certification プログラムにおける CIBA Conformance Profile の実装にも携わっており、本論点は certification 観点での実装者間の摩擦から導かれたと推定される（ただし起票投稿本文には certification 文脈の明示記述はない）。

本投稿への ML 上の即時返信はなされず、3/26 アジェンダで Issue Tracker サブ項目として組み込まれることで WG コール内討議への持ち越しが確定する（[2024 年 3 月レポート](./2024-03.md) §2 参照）。

### 推定される 2/27 コール内議題

議事録 non-public 運用下では、2/27 コール内の具体的議論を公開チャネルから直接確認することはできない。ただし、アジェンダ細目から推定される議題は以下のとおりである。

- **GSMA Liaison**: GSMA は MODRNA WG の設立来の協業相手であり、Mobile Connect / RCS / Automotive Identity (AiD) 領域での継続的な調整事項を扱う恒常的議題。WG ページの GSMA 協業領域表記と整合
- **CAMARA Project / Bitbucket Issue #215 / FAPI Issue #630**: Android 上で MNO が提供する OpenID API を MODRNA WG 仕様群と FAPI WG 仕様群のどちらでカバーするかという責任分界点
- **FAPI Issue #632 (Security profile for CAMARA) + FAPI Presentation**: CAMARA プロジェクト向けに OAuth 2.0 / OpenID Connect ベースのセキュリティプロファイルを定義する FAPI 側 Issue。FAPI WG 側からのプレゼン枠でステータス共有
- **eKYC-IDA Presentation**: eKYC-IDA WG からのプレゼン枠。本月後段の動向（4 月の CAMARA `purpose` パラメータ議論）に繋がる、ID 保証領域での CAMARA 連携論点の先取りと推定される
- **Issue Tracker**: 本月時点で Bitbucket Cloud (`bitbucket.org/openid/mobile/issues`) の現状参照のみ。コール終了翌日に Heenan が Issue #218 を ML 起票することは、本コール内では予見されていなかった

これらアジェンダ細目のうち、CAMARA Project サブ項目（Bitbucket Issue #215 / FAPI #630 / FAPI #632）は 3/26 アジェンダにも継承されるが（`FAPI Presentation` の言及は外れる）、4/9 アジェンダではすべて脱落する（[2024 年 4 月レポート](./2024-04.md) §3 参照）。

## 5. GitHub 上の議論

MODRNA WG の仕様ソースは GitHub ではなく Bitbucket Cloud (`bitbucket.org/openid/mobile/src/master/`) で管理されている。GitHub 側に MODRNA WG の公式一次リポジトリは存在しない（`github.com/openid/MODRNA` といった誤記が一部で見られるが、そのようなリポジトリは現存しない）。

Bitbucket Cloud は SPA 描画のため外部からのクローリングに適さず、本稿の調査範囲では 2 月中の Bitbucket Issue / PR / コミット活動の網羅的件数を確認できない。ただし、(i) 2/27 アジェンダで明示されていた Bitbucket Issue #215 (Android Carrier OpenID API) は本月時点で **オープン状態を維持** していたと推定される（3/26 アジェンダでも引き続き参照）、(ii) Issue #218 (CIBA Errata: overstrict `invalid_client`) は 2/28 の ML 起票と同時に Bitbucket 上でも Issue として登録されたと推定される（3/26 アジェンダの Issue Tracker サブ項目として明示される）、(iii) MODRNA WG の ML 上で 2 月中に Bitbucket 由来の自動通知メールが一切観測されない、(iv) 2/27 アジェンダの "Specification Status" 項目が `openid.net/wg/mobile/status/` への単純リンクに留まり具体的な版番号更新計画を欠くこと、から、Bitbucket 上でも本月は目立った新規動作はなかったと推定できる。

FAPI WG 側の Bitbucket Issue [#630 (Android Carrier OpenID API)](https://bitbucket.org/openid/fapi/issues/630/android-carrier-openid-api) と [#632 (Security profile for CAMARA)](https://bitbucket.org/openid/fapi/issues/632/security-profile-for-camara) は 2/27 MODRNA アジェンダに External Organizations 参照リンクとして含まれていたが、FAPI WG 側の本月の活動状況は MODRNA WG 月次レポートのスコープ外である。

なお、Atlassian による Bitbucket Cloud Issues / Wiki の 2026-08-20 完全廃止アナウンスは本時点（2024 年 2 月）では未公表（2026 年 3 月公表）であり、MODRNA WG として Issue Tracker 代替候補を検討する動きは本月の公開チャネルには存在しない。

## 6. 関連イベント

### MWC Barcelona 2024（2024-02-26 〜 2024-02-29、Fira Gran Via, Barcelona, Spain）

本月の **モバイル産業最大の年次イベント**。GSMA 主催の Mobile World Congress 2024 が Fira Gran Via で 2/26-29 の 4 日間にわたり開催された。MODRNA WG の協業相手である GSMA は本イベントの主催者であり、Mobile Connect / RCS / Automotive Identity (AiD) 等の MODRNA WG 連携プロダクト群は MWC で例年プロモーション枠を持つ。

ただし、本 MWC 2024 における MODRNA WG 共同議長（Bjorn Hjelm / John Bradley）の現地参加・登壇記録は MODRNA WG ML 上には共有されていない。`openid.net/tag/modrna/` 上にも 2024 年 2 月付の MWC 関連アナウンスは存在しない。2/27 MODRNA WG コール（14:00 UTC = 中央欧州時間 15:00、バルセロナ現地時間 15:00）は MWC 2 日目と完全に時期重複しているが、コール開催を MWC 出席のため延期・キャンセルした形跡は ML 上にはなく、通常通り開催されたと推定される（2/27 にアジェンダ ML 投稿が確認できるため）。

MWC Barcelona 2024 では、GSMA Open Gateway イニシアチブの拡大が中心トピックとなり、CAMARA プロジェクト（Linux Foundation 配下の Telco API Alliance）の進展が GSMA・Telco・ハイパースケーラー間の連携の中核として位置づけられた。MODRNA WG の対象領域（CIBA Core / MODRNA Authentication Profile）は CAMARA セキュリティプロファイルの参照標準として位置づけられる関係にあり、2/27 MODRNA アジェンダで External Organizations / CAMARA Project サブ項目に Bitbucket Issue #215 / FAPI #630 / FAPI #632 が参照されているのは、この MWC 期間中の GSMA / CAMARA 動向と並走する論点整理である。

### CAMARA プロジェクトの参照標準位置付け（背景）

Linux Foundation 配下の Telco API Alliance である CAMARA プロジェクトは、後の 9 月 16 日に予定する初の正式メタリリース（Meta-Release Fall24）に向けて API の品質検証・統合作業を進めていた期間。CAMARA Security and Interoperability Profile は OAuth 2.0 / OpenID Connect 基本仕様群を基盤とし、特に OIDC Authorization Code Flow / CIBA / OAuth2 Client-Credentials / OAuth2 JWT Bearer の 4 フローをサポートする方針が確立していた。MODRNA WG にとって CIBA Core と MODRNA Authentication Profile は CAMARA セキュリティプロファイルの主要参照標準として位置づけられる関係にあり、2/27 MODRNA アジェンダで External Organizations の CAMARA Project サブ項目に FAPI Issue #632 (Security profile for CAMARA) が参照リンクとして明示されているのは、この相互参照関係を反映している。

OpenID Foundation は 2023 年 11 月以来 CAMARA の Associate Member として参加しており、本月時点で MODRNA WG・FAPI WG・eKYC-IDA WG の 3 WG が CAMARA 関連論点を並行追跡している。2/13 Hjelm 議長欠席メールの「CAMARA に関するフィードバックは別途やり取りする」との一文も、この多 WG 並行追跡体制を反映した発信である。

## 7. 今後の予定（2024 年 2 月末時点の視点）

2 月末時点の公開情報からは、MODRNA WG の 3 月以降の明示的な予定は ML・`openid.net` いずれにも掲載されていない。隔週カデンスと月内事象から推定される事項は以下のとおり。

- **定例コール**: 隔週火曜サイクル（2/13 議長欠席、2/27 開催）に従えば、3 月の候補日は 3 月 12 日（火）と 3 月 26 日（火）の 2 回。3/12 は IETF 119 Brisbane 開催（3/16-24）の直前週、3/26 は IETF 119 終了後の週にあたる — 実際に 3/12 は完全サイレント、3/26 は標準 8 項目アジェンダ + サブ項目明示版として ML 投稿される（[2024 年 3 月レポート](./2024-03.md) 参照）
- **CIBA Errata Issue #218 の扱い**: 2/28 起票直後で、3 月コール内での口頭討議への持ち越しが見込まれる。CIBA Core 1.0 errata 化が必要かどうか、必要な場合の編集スケジュールが論点となる見込み — 実際に 3/26 アジェンダの Issue Tracker サブ項目として組み込まれる
- **CAMARA Project 連携の継続**: Bitbucket Issue #215 (Android Carrier OpenID API)、FAPI Issue #630・#632 (Security profile for CAMARA) の各 Issue は本月時点でいずれもオープン状態を維持。CAMARA Meta-Release Fall24（9/16 予定）に向けた CAMARA Security and Interoperability Profile の確定作業が並走する見込み
- **eKYC-IDA WG との連携深化**: 2/27 アジェンダで明示された `eKYC-IDA Presentation` の流れは、後の 4 月（eKYC-IDA WG ML 上の "Move transaction specific purpose out of the main specification" スレッドで Bjorn Hjelm が CAMARA `purpose` パラメータ議論に積極参加）に繋がる伏線となる
- **IETF 119 Brisbane（3/16-24）**: 北米・欧州・豪州 IAM 関係者の主要関心事項。MODRNA WG コアメンバー（Bjorn Hjelm / John Bradley 等）の現地参加は通例
- **OpenID Foundation Workshop（4/15、Sunnyvale, Google）**: 本月時点で MODRNA WG Update 枠（15 分枠）の登壇が想定される。Bjorn Hjelm の登壇が後に確認される
- **Implementer's Draft 群の現状維持**: MODRNA Authentication Profile ID1 / Account Porting ID1 / User Questioning API ID2 はいずれも次版改訂の公式アナウンスがなく、現行ステータスを維持

2 月の対外可視な活動は (i) 議長 1 名による 2/13 議長欠席連絡 ML 投稿 1 通、(ii) 議長 1 名による 2/27 コール用アジェンダ ML 投稿 1 通（External Organizations / CAMARA Project + Bitbucket Issue #215 / FAPI #630 / FAPI #632 / FAPI Presentation / eKYC-IDA Presentation の最大限明示列挙版）、(iii) Joseph Heenan による 2/28 CIBA Errata Issue #218 起票 ML 投稿 1 通、の 3 件に集約される。当時の読者にとっては「MWC Barcelona 2024 開催月でありながら MODRNA ML 上ではアジェンダ周辺の事務連絡 3 通の静粛な月」として記憶される月であり、後の月から振り返ると、本月は 2024 年通年で唯一 `eKYC-IDA Presentation` がアジェンダに明示された月であり、かつ CIBA Errata Issue #218 が起票された月という二重の意味で、3 月以降の MODRNA WG 運用の **起点となる月** として位置づけられる。
