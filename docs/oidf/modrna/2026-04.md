# OpenID Foundation MODRNA WG 活動レポート (2026年4月)

> 執筆日: 2026-05-18。本記事は 2026年4月 の活動を遡及的にまとめたものです。

## 1. 概要

MODRNA (Mobile Operator Discovery, Registration & autheNticAtion) WG は、モバイルネットワーク事業者 (MNO) がアイデンティティサービスをリライングパーティ (RP) に提供する際に適した OpenID Connect プロファイルを開発する OpenID Foundation のワーキンググループです。GSMA の Mobile Connect エコシステムをサポートする目的で設立され、CIBA (Client-Initiated Backchannel Authentication) Core 1.0 を Final Specification として送り出した実績を持ちます。

2026年4月の MODRNA WG は、公開情報の範囲では実質的な公開活動が確認できない月となりました。隔週火曜開催の WG コール（4月7日に予定されていた回）は議長の予定衝突により直前にキャンセルされ、その後に予定されていたであろう 4月21日週の回についても開催・キャンセルいずれの公開告知も `openid-specs-mobile-profile` メーリングリストに記録されていません。`openid.net` 上の MODRNA タグでも、当月の MODRNA 固有のアナウンスは確認できませんでした。

## 2. 公開された仕様・ドラフト改訂

2026年4月に MODRNA WG が発行したパブリックレビュー告知・投票通知・Implementer's Draft の改訂は、`openid.net` のニュース一覧および MODRNA タグページに掲載されていません。

参考として、MODRNA WG が保守している主な仕様群の現行ステータスは次のとおりです（4月時点で変更なし）。

## 3. ミーティングと議論

MODRNA WG のミーティング議事録は非公開のため、ここでは公開メーリングリストから読み取れる範囲を記述します。

### 4月7日 (火) 定例コール: キャンセル

WG 共同議長の Bjorn Hjelm から、4月7日 12:58 UTC に「REMINDER - MODRNA WG Call Apr. 7 Canceled」と題したメッセージが `openid-specs-mobile-profile` に投稿され、当日のコールが議長の予定衝突によりキャンセルされた旨が周知されました。本文は以下の 1 文のみで、議題・再開予定・持ち越し事項への言及はありません。

> today's MODRNA WG call is been canceled due to chair's meeting conflict today.
> ([openid-specs-mobile-profile 2026-04-07 投稿](https://lists.openid.net/pipermail/openid-specs-mobile-profile/Week-of-Mon-20260406/002004.html) より)

MODRNA WG のコールは「Every 2 weeks from 08:00 to 09:00 on Tuesday (MDT)」のカデンスで運用されており（4月1日に Brent Zundel から配信された Google カレンダーの "Updated invitation" / "Synced invitation" によって確認可能）、4月7日の次回開催は隔週カデンスに従えば 4月21日に該当します。しかし、4月21日週（Week-of-Mon-20260420）および 4月27日週（Week-of-Mon-20260427）の ML 週次インデックスは公開アーカイブに存在せず、4月21日のコール開催/キャンセル告知・議事連絡は記録されていません。

### 公開議論の状況

上記キャンセル通知と、月初に配信されたコール用のカレンダー招待更新メール 2 通（Brent Zundel 投稿、いずれも 4月1日 14:37 UTC、内容は「Updated invitation: MODRNA WG @ Every 2 weeks from 08:00 to 09:00 on Tuesday (MDT)」と "Synced invitation: ..." の自動送信）を除き、2026年4月の `openid-specs-mobile-profile` には技術的な議論を含む投稿はありません。返信スレッドも形成されていません。

## 5. GitHub 上の議論

MODRNA WG の公式仕様リポジトリは Bitbucket Cloud (`https://bitbucket.org/openid/mobile/`) に置かれており、`github.com/openid` Organization 配下には MODRNA の公式リポジトリは存在しません。したがって GitHub 上での該当月の議論は対象外となります。

Bitbucket Cloud Issues / Wiki は 2026-08-20 に完全削除予定であることが Atlassian から告知されており、MODRNA WG の議論基盤の移行が今後の論点となり得ますが、4月の公開アナウンスに移行に関する具体的な動きは確認できませんでした。

## 6. 関連イベント

- **OpenID Foundation Hybrid Workshop (2026-04-27)** — Spring 2026 IIW の前日にあたる 4月27日 (月) に、Cisco のサンノゼオフィス (カリフォルニア州) およびオンラインのハイブリッド形式で開催が告知されました。"What's New at OIDF"、"Working Group Updates"、"Discussion on Emerging Digital ID trends"、"Deep dive into our latest white papers" の 4 セッションを軸とする旨が予告されており、MODRNA を含む各 WG のアップデートが Working Group Updates 枠で扱われる可能性があります。当月時点では詳細アジェンダは未公開で、MODRNA 固有のセッションが組まれるか否かは明示されていません。
- **Spring 2026 IIW** — 4月28日から始まる IIW の前日プログラムとして上記ワークショップが組まれていることが、4月の MODRNA を取り巻く主な外部文脈です。MODRNA WG メンバーによる IIW セッション登壇については、公開記録の範囲で当月中の確認はできませんでした。

## 7. 今後の予定 (2026年4月末時点の視点)

2026年4月末時点の公開情報から読み取れる、5月以降の MODRNA WG に関する確定的な予定事項は確認できませんでした。以下は隔週カデンスから推定される事項です（公開告知ではない点に注意）。

- 隔週火曜のカデンスに従えば、次回 WG コールは 5月5日 (火) または 5月19日 (火) のいずれかに開催される見込み
- GSMA Mobile Connect、CAMARA、3GPP/RCS との接続作業は継続中とみられるが、4月時点で公開された具体的なマイルストーン告知はなし
- Bitbucket Cloud Issues/Wiki の 8月20日廃止に向け、リポジトリ移行の検討が今後発生する可能性
