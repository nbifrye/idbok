# OpenID Foundation MODRNA WG 活動レポート (2025年10月)

> 執筆日: 2026-04-25（遡及執筆）

## 1. 概要

MODRNA WG（Mobile Operator Discovery, Registration, & autheNticAtion Working Group）は、モバイルネットワークオペレータ（MNO）が OpenID Connect / OAuth 2.0 をベースに認証サービスを提供する際の相互運用プロファイルを策定するワーキンググループである。共同議長は Bjorn Hjelm と John Bradley（Yubico）の2名。定例コールは隔週火曜日2pm UTC（7am PDT / 4pm CEST）に GoToMeeting で開催される運用となっている。仕様ソースは Bitbucket（`bitbucket.org/openid/mobile/`）で歴史的に管理されており、議事録は non-public 運用である。

2025年10月の MODRNA WG は、**ML 投稿が3件のみ**（うち2件は10月21日定例コールのキャンセル通知、残り1件は OIDF 事務局からのポリシー周知）という極めて静かな月であった。10月21日コールの中止理由は **Internet Identity Workshop 41（IIW 41、10月21〜23日 Mountain View）参加メンバーへの配慮** であり、Bjorn Hjelm のキャンセル通知に「Enjoy IIW for those attending」と記されていることから WG 主要メンバーが IIW へ移動していたことが読み取れる。

主要ドラフト（CIBA Core Final、MODRNA Authentication Profile ID1、Account Porting ID1、User Questioning API ID2）の改訂は10月中に確認できなかった。本レポートでは公開情報から観測可能な範囲を中心に整理し、推測で内部活動を補完することは避ける。

## 2. 公開された仕様・ドラフト改訂

2025年10月中に openid.net/specs 配下で新規に公開された MODRNA 仕様ドラフトは確認できなかった。MODRNA WG の主要ドラフト群の状態（10月末時点）は以下のとおり:

| 仕様                                                              | ステータス            |
| ----------------------------------------------------------------- | --------------------- |
| OpenID Connect Client Initiated Backchannel Authentication – Core | Final                 |
| OpenID Connect MODRNA Authentication Profile                      | Implementer's Draft 1 |
| OpenID Connect Account Porting                                    | Implementer's Draft 1 |
| OpenID Connect User Questioning API                               | Implementer's Draft 2 |
| OpenID Connect MODRNA Discovery Profile                           | Working Draft         |
| OpenID Connect MODRNA Registration Profile                        | Working Draft         |
| Client Initiated Backchannel Authentication Profile (MODRNA 版)   | Working Draft         |

これらの版番号・ステータスは10月初旬時点と10月末時点で変化していない。

## 3. ミーティングと議論

MODRNA WG の議事録は non-public 運用のため、定例コールの議題・参加者・決定事項は公開されていない。ML 上のキャンセル通知から以下が再構成される:

| 日付            | コール | 状態                                                                                                                  |
| --------------- | ------ | --------------------------------------------------------------------------------------------------------------------- |
| 2025-10-07 (火) | 定例   | 開催が推定される（10月21日キャンセル通知に「As discussed on the last call」とあり、その「last call」が10月7日に該当） |
| 2025-10-21 (火) | 定例   | **中止**。IIW 41 と日程が衝突するため、前回コール時点で WG が事前合意したキャンセル                                   |

10月7日コールの内容自体は ML にも openid.net にも公開記録がなく、Bitbucket のコミット活動からも10月分の具体的な仕様変更は確認できなかった。10月21日コールキャンセルは前回コール時点で既に決まっており、「IIW 参加者を優先する」という運用判断が示された。

議事録が non-public な MODRNA では、本来 ML / GitHub から議論を再構成するのが代替手段となるが、10月の ML が事務連絡のみであり、Bitbucket 側の Issue / Wiki も外部から確認できないため、本節で実質的な技術議論を記述することができない。

### 4.1 "New OpenID Foundation Notes & Recordings Policy"（Mike Leszcz, 10月9日 13:50:28 UTC）

OIDF 事務局からの WG 横断アナウンス。10月以降の全 WG における議事録・録音公開運用の改訂を周知する内容で、MODRNA 固有の技術議論ではない。

### 4.2 "REMINDER - MODRNA WG Call Canceled" / "Canceled event: MODRNA WG @ Tue Oct 21, 2025 7am - 8am (PDT)"（Bjorn Hjelm, 10月21日）

10月21日 13:58:11 UTC と 14:47:50 UTC の2件として配信された定例コールキャンセル通知。1件目はリマインダ形式で「As discussed on the last call, this is a reminder that the MODRNA WG call today, Oct. 21, has been canceled. Enjoy IIW for those attending.」と記述されており、2件目は GoToMeeting/カレンダーシステムによる Canceled event 通知の自動配信である。

このスレッドから以下が読み取れる:

- 10月21日コールのキャンセルは前回（10月7日）コール時点で既に WG 内で合意されていた
- キャンセル理由は IIW 41 との日程衝突であり、Bjorn Hjelm 自身を含む主要メンバーが IIW 参加側に回ることを WG として尊重した
- MODRNA WG の運営スタイルとして、対外イベントを優先するために定例コールを柔軟に取りやめる傾向が見られる

10月中に上記2スレッド以外の技術的議論は ML 上に投稿されなかった。

## 5. GitHub 上の議論

MODRNA WG の仕様ソースは GitHub ではなく Bitbucket Cloud（`bitbucket.org/openid/mobile/`）で管理されている。Bitbucket Cloud の Issue / Wiki は SPA 描画のため外部のクローリングに適さず、本稿の調査範囲では10月中の Issue / PR / コミット活動の具体的件数を確認できなかった。

GitHub 側に MODRNA の公式一次リポジトリは存在しない（過去に `github.com/openid/MODRNA` 等の誤記が出回ることがあるが、そのようなリポジトリは現存しない）。

なお Bitbucket Cloud の Issues / Wiki は2026年8月20日に完全削除予定であることが Atlassian から告知されており、OpenID Foundation 側でも GitHub 等への移行先検討が必要となるが、本レポート対象月時点では具体的な移行計画は MODRNA WG 内で公表されていない。

## 6. 関連イベント

### IIW 41（2025年10月21〜23日）

カリフォルニア州 Mountain View の Computer History Museum で開催。10月21日 MODRNA WG コールのキャンセル理由として明示されており、Bjorn Hjelm をはじめとする主要メンバーが現地参加していた。MODRNA 固有のセッション記録は iiw.idcommons.org 上で確認できなかったが、モバイル事業者の OpenID 採用や CIBA 実装に関する議論は IIW の常連トピックであり、非公式な情報交換の場として機能した可能性が高い。

### OIDF Cisco Workshops（2025年10月20日）

OpenID Foundation と Cisco の共催ワークショップ。他 WG（eKYC-IDA、IPSIE、ESCG 等）のアジェンダで言及されたエコシステム横断イベント。MODRNA 関係者の参加有無は公開情報からは確認できない。

### IETF 124 Montreal（2025年11月1〜7日）予告

10月末時点で開催直前。OAuth WG / DPoP / トークンバインディング系の議論が CIBA 実装と関連するため、一部メンバーが参加準備を進めていた可能性はあるが、MODRNA WG として公式アナウンスは確認できなかった。

## 7. 今後の予定（2025年10月末時点の視点）

公開情報からは、MODRNA WG の11月以降の明示的な予定は確認できなかった。推測される継続活動:

- **隔週火曜日 2pm UTC** の定例コール再開（次回は10月21日キャンセル後の11月初旬コール）
- **ID2 / ID3 への昇格候補**: User Questioning API 以外の Implementer's Draft 群（Authentication Profile、Account Porting）の次版改訂検討
- **CIBA Core Final 後のメンテナンス**: Final 公開済みスペックの Errata 整理
- **Bitbucket → GitHub 移行検討**（2026年8月20日の Bitbucket Cloud Issues/Wiki 廃止に向けて）

10月時点の WG 活動の対外可視性は極めて低く、当時の読者にとっては「定例コールのキャンセル以外に動きが見えない静かな月」として認識されていたと言える。
