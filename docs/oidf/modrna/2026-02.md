# OpenID Foundation MODRNA WG 活動レポート (2026年2月)

> 執筆日: 2026-04-18。本記事は 2026年2月 の活動を遡及的にまとめたものです。

## 1. 概要

MODRNA (Mobile Operator Discovery, Registration & autheNticAtion) WG は、モバイルネットワーク事業者 (MNO) がアイデンティティサービスをリライングパーティに提供する際に適した OpenID Connect プロファイルを開発する OpenID Foundation のワーキンググループです。GSMA との協力のもと、Mobile Connect エコシステムのサポートを主目的として設立されました。CIBA (Client-Initiated Backchannel Authentication) の生みの親であり、自動車アイデンティティ (AiD) や RCS といった新領域でも GSMA・3GPP との連携を継続しています。

2026年2月については、メーリングリストアーカイブを直接確認したところ、対象期間に投稿されたメッセージが存在しないことを確認しました（アーカイブは 2025年12月29日週の次が 2026年3月30日週となっており、2026年1〜3月上旬の投稿ゼロが確認されました）。MODRNA WG はミーティング議事録が非公開であり、GitHub リポジトリも 404 を返すため、2026年2月については公開記録を確認できなかった月となります。

## 3. 公開記録が確認できなかった項目（ミーティング・ML・GitHub）

MODRNA WG のミーティング議事録は非公開です。以下の一次情報源を調査しましたが、2026年2月の活動記録を確認できませんでした。

### メーリングリスト

- 対象アーカイブ: `https://lists.openid.net/pipermail/openid-specs-mobile-profile/`
- 結果: アーカイブのトップページを直接取得し、全週のインデックスを確認した。2025年12月29日週（Week of Mon 20251229）の次のエントリが 2026年3月30日週（Week of Mon 20260330）であり、2026年1月〜3月上旬にわたって投稿がゼロであることが確認された。
- 2026年2月に `openid-specs-mobile-profile` に投稿されたメッセージは存在しない。

### GitHub

- SKILL.md に登録されているリポジトリ URL `https://github.com/openid/MODRNA` は 404 を返した。MODRNA WG の公式リポジトリは GitHub ではなく Bitbucket（`https://bitbucket.org/openid/mobile/`）に置かれている。調査期間中は WG ページ自体が 503 を返したため Bitbucket URL を特定できなかったが、後日 WG ページが復旧した際に確認した。

### まとめ

上記の調査を踏まえ、2026年2月の MODRNA WG に関する公開活動記録は存在しなかった（ML 投稿ゼロを実確認）。MODRNA は従来から活動の表面化が少ない WG であり、2026年2月は実質的な公開活動がなかった月と判断される。
