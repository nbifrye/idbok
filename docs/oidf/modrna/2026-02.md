# OpenID Foundation MODRNA WG 活動レポート (2026年2月)

> 執筆日: 2026-04-18。本記事は 2026年2月 の活動を遡及的にまとめたものです。

## 1. 概要

MODRNA (Mobile Operator Discovery, Registration & autheNticAtion) WG は、モバイルネットワーク事業者 (MNO) がアイデンティティサービスをリライングパーティに提供する際に適した OpenID Connect プロファイルを開発する OpenID Foundation のワーキンググループです。GSMA との協力のもと、Mobile Connect エコシステムのサポートを主目的として設立されました。CIBA (Client-Initiated Backchannel Authentication) の生みの親であり、自動車アイデンティティ (AiD) や RCS といった新領域でも GSMA・3GPP との連携を継続しています。

2026年2月については、メーリングリストアーカイブを直接確認したところ、対象期間に投稿されたメッセージが存在しないことを確認しました（アーカイブは 2025年12月29日週の次が 2026年3月30日週となっており、2026年1〜3月上旬にかけて投稿ゼロでした）。MODRNA WG はミーティング議事録が非公開であり、仕様リポジトリは GitHub ではなく Bitbucket（`bitbucket.org/openid/mobile/`）に置かれているため、2026年2月については表面化した公開活動の記録が存在しない月となります。

## 3. 公開記録の状況（ミーティング・ML・リポジトリ）

MODRNA WG のミーティング議事録は非公開です。以下の一次情報源を確認しました。

### メーリングリスト

- 対象アーカイブ: `https://lists.openid.net/pipermail/openid-specs-mobile-profile/`
- アーカイブのトップページで全週のインデックスを確認したところ、2025年12月29日週（Week of Mon 20251229）の次のエントリが 2026年3月30日週（Week of Mon 20260330）であり、2026年1月〜3月上旬にかけて投稿ゼロであることが確認された。
- したがって 2026年2月に `openid-specs-mobile-profile` に投稿されたメッセージは存在しない。

### リポジトリ

- MODRNA WG の公式仕様リポジトリは GitHub ではなく Bitbucket（`https://bitbucket.org/openid/mobile/`）に置かれている。`github.com/openid` Organization 配下に `MODRNA` という名称のリポジトリは存在しない。
- 本レポートでは Bitbucket 上の個別 commit・issue 履歴までは辿っていない。

### まとめ

上記の調査を踏まえ、2026年2月の MODRNA WG に関する公開メーリングリスト投稿は存在しない（ML 投稿ゼロを実確認）。MODRNA は従来から活動の表面化が少ない WG であり、2026年2月は ML 上の公開活動がなかった月と判断される。
