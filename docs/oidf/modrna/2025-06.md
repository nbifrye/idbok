# OpenID Foundation MODRNA WG 活動レポート (2025年6月)

> 執筆日: 2026-04-29（遡及執筆）

## 1. 概要

MODRNA WG (Mobile Operator Discovery, Registration, & autheNticAtion Working Group) は、モバイルネットワークオペレータ (MNO) が OpenID Connect / OAuth 2.0 をベースにアイデンティティサービスを提供する際の相互運用プロファイルを策定するワーキンググループである。共同議長は Bjorn Hjelm と John Bradley (Yubico) の 2 名で、定例コールは隔週火曜日 2pm UTC (7am PDT / 4pm CEST) に GoToMeeting で開催される運用となっている。仕様ソースは Bitbucket (`bitbucket.org/openid/mobile/`) で歴史的に管理されており、議事録は non-public 運用である。

2025 年 6 月の MODRNA WG は、それ以降の夏季サイレント期 (7 月の ML ゼロ投稿 → 8 月のキャンセル通知 1 件のみ → 9 月の完全静寂) に入る直前の **本年中で最もアクティブな月の一つ** であった。`openid-specs-mobile-profile` メーリングリストの公開アーカイブには 6 月分として 2 週分の週次インデックスが存在する:

- Week-of-Mon-20250602: 6 件のスレッド (6 月 3 日に集中)。Bjorn Hjelm によるアジェンダ、Issue #215 (Android Carrier OpenID API) のクローズ提案を巡る Bjorn Hjelm と Axel Nennker (Deutsche Telekom) のやり取り、Bjorn Hjelm による Issue #220 / #221 (WG ドキュメント更新) の起票通知
- Week-of-Mon-20250616: 1 件 (Bjorn Hjelm による 6 月 17 日コール向けアジェンダ)

6 月 9 日週・6 月 23 日週・6 月 30 日週はインデックスファイル自体が存在せず、これらの週の ML 公開投稿はゼロである。隔週火曜サイクルから推定される 6 月の定例コール候補日は 6 月 3 日と 6 月 17 日で、双方ともアジェンダ投稿が ML に流れていることから、いずれも開催された蓋然性が高い (議事録は non-public のため確証は取れない)。

技術的には、Issue #215 をめぐる Bjorn Hjelm と Axel Nennker の短いやり取りが、MODRNA WG が抱える本質的論点 — **OS レベルで「キャリアの OpenID Provider」をモバイルアプリに知らせる手段が存在しないこと**、および **GSMA ASAC / TS.43 におけるアグリゲータ経由のトークンルーティング設計を OpenID Connect 仕様にどう接続するか** — を浮かび上がらせた点で記録すべき内容を含んでいる。

## 3. ミーティングと議論

MODRNA WG の議事録は non-public 運用のため、定例コールの議題・参加者・決定事項は公開されていない。6 月の隔週火曜日サイクルから推定される定例コール候補日と公開記録は以下のとおり:

| 日付            | コール | 公開記録                                                |
| --------------- | ------ | ------------------------------------------------------- |
| 2025-06-03 (火) | 定例   | Bjorn Hjelm によるアジェンダ投稿 (2025-06-03 14:08 UTC) |
| 2025-06-17 (火) | 定例   | Bjorn Hjelm によるアジェンダ投稿 (2025-06-17 14:01 UTC) |

両コール向けのアジェンダ投稿はいずれも `Roll Call` / `Antitrust Statement` / `Adoption of the Agenda` / `External Organizations and Events` / `Specification Status` / `OpenID Certification for MODRNA` / `Issue Tracker` / `AOB` という MODRNA WG 標準の項目構成を踏襲したものである。アジェンダ本文には毎回 OIDF Antitrust Policy の遵守義務 (「The OIDF Antitrust Policy, and any applicable U.S. and international antitrust and competition law, governs the conduct of all attendees」) が冒頭で確認されており、MNO 系参加者が中心となる WG として競争法配慮を都度明示する姿勢が貫かれている。

議事録が non-public な MODRNA では、コール内で具体的にどの議題にどれだけ時間が割かれたかは ML から再構成するしかない。6 月 3 日コールについては **その同日に Bjorn Hjelm が以下のフォローアップ投稿を ML に行っている** ため、コール内議論との連続性を辿れる:

- 14:53 UTC: Issue #215 (Android Carrier OpenID API) について「次の MODRNA WG 会合までに反対意見がなければクローズ」と提案
- 15:07 UTC: Issue #220 を起票し ML に通知 (MODRNA WG Overview ページの最新化)
- 15:09 UTC: Issue #221 を起票し ML に通知 (MODRNA WG Spec ページの Resources 更新)
- 17:37 UTC: Issue #215 に関する Axel Nennker (Deutsche Telekom) の返信に対し、クローズ理由を「working group として有効な action を見いだせなかったため」と再確認

これらの投稿が同日昼〜夕方に集中していることから、6 月 3 日コール内の Issue Tracker レビューで Issue #215 のクローズ方針および Overview / Spec ページ刷新方針が議論され、コール直後に Bjorn Hjelm が ML へ反映する、というワークフローが観測される。6 月 17 日コールについては同様のフォローアップ投稿が ML 上にないため、コール内容の再構成は困難であるが、アジェンダに `Issue Tracker` 項目が継続的に置かれていることから、Issue #215 のクローズ予告 (6 月 3 日に「次の MODRNA WG meeting までに反対なければクローズ」と通告) を踏まえ、6 月 17 日コールでクローズ判断が下された可能性が高い。Bitbucket Issue Tracker が外部から確認できないため最終ステータスは不明である。

### 4.1 Issue #215 - Android Carrier OpenID API のクローズ提案 (2025-06-03 開始)

- [Proposed close - Issue #215 (Bjorn Hjelm, 2025-06-03 14:53 UTC)](https://lists.openid.net/pipermail/openid-specs-mobile-profile/Week-of-Mon-20250602/001988.html)
- [Proposed close - Issue #215 (Axel Nennker, 2025-06-03 15:03 UTC)](https://lists.openid.net/pipermail/openid-specs-mobile-profile/Week-of-Mon-20250602/001989.html)
- [Proposed close - Issue #215 (Bjorn Hjelm, 2025-06-03 17:37 UTC)](https://lists.openid.net/pipermail/openid-specs-mobile-profile/Week-of-Mon-20250602/001992.html)

Bjorn Hjelm (共同議長) が「Issue #215 を次回 MODRNA WG 会合までにコメントがなければクローズする」と提案したことが発端。Issue #215 の対象は **Android プラットフォームにおける「キャリアの OpenID API」のサポート** に関する論点で、過去に MODRNA WG で扱われたものの実質的な action item に到達していなかった。

これに対し Issue #215 を ML 投稿当時もっとも近接した立場から扱っていた Axel Nennker (Deutsche Telekom) が即日返信。Nennker の主張は以下の 3 点に整理できる:

1. 自身は Issue #215 の作業を継続できておらず、「Probably the discussion in the MODRNA WG which I failed to participate in」と参加機会を逸した点を率直に認めている
2. Android プラットフォームに対しては別途 feature request (Android issue tracker の Issue 308240647) として「キャリアの OpenID 機能」の追加を要望しており、これは現在も活発に動いている
3. **GSMA ASAC および GSMA TS.43 では、アグリゲータが TS.43 トークンを「どの OpenID Provider に対して」ルーティングすべきかが活発に議論されている** ため、OS 側で「モバイルアプリがオペレータの OpenID Provider を知る手段」が提供されるか否かで結論が大きく変わる

Nennker の指摘は、MODRNA が長年抱える根本問題 — **MNO の OpenID Provider 発見が OS API で支援されない限り、アグリゲータ層の独自実装が増殖する** — を端的に突くものである。

Bjorn Hjelm の最終返信 (同日 17:37 UTC) では、クローズ提案そのものは「the proposal to close the issue because we couldn't determine any action by the working group」と再確認しつつ、GSMA 側の議論について「the groups should really reach out to the OpenID Foundation for assistance and guidance to make sure that OpenID Connect is implemented correctly」と、GSMA からの正式な相談チャネル開設を期待する立場を表明している。Nennker が指摘した「OS が MNO の OpenID Provider をモバイルアプリに知らせる手段」 (原文: "That discussion would be much different if the operating system provided a way for a mobile application to know the operator's openid provider") の論点を踏まえれば、OS ベンダー (Android = Google) の対応次第で MODRNA 周辺の議論全体が動きうる構造が浮かび上がる。

スレッドはこの時点で実質的に決着しており、Issue #215 自体は「WG として有効な action item を見いだせず」を理由にクローズ方針が固まった。一方で **裏側の論点 (GSMA ASAC / TS.43 とのコーディネーション、Android OS API の動向) は MODRNA WG 内で未決のまま 7 月以降のサイレント期に持ち越される** 形となっている。

## 5. GitHub 上の議論

MODRNA WG の仕様ソースは GitHub ではなく Bitbucket Cloud (`bitbucket.org/openid/mobile/`) で管理されている。Bitbucket Cloud の Issue / Wiki は SPA 描画のため外部のクローリングに適さず、本稿の調査範囲では 6 月中の Issue / PR / コミット活動の具体的件数を確認できなかった。

ただし **ML から間接的に判明する Bitbucket Issue 活動** として、6 月 3 日に Issue #220 (MODRNA WG Overview ページ更新)、Issue #221 (MODRNA WG Spec ページ Resources 更新) が新規起票され、Issue #215 (Android Carrier OpenID API) のクローズ提案が出されている。これらは Bitbucket 側で確認できれば本来 §5 の中心となる議論であるが、外部から内容を直接取得できないため、§4 の ML スレッドからの再構成で代替している。

GitHub 側に MODRNA の公式一次リポジトリは存在しない (`github.com/openid/MODRNA` といった誤記が出回ることがあるが、そのようなリポジトリは現存しない)。本サイト (idbok) の `docs/oidf/modrna/index.md` 内に同種の誤リンクが含まれている点は別途修正対象である。

## 6. 関連イベント

### 6 月の OIDF 全体動向

MODRNA WG の領域外ではあるが、OpenID Foundation は 2025 年 6 月に IIW XL (40th Internet Identity Workshop, 2025-04-08〜10 開催) のフォローアップ、EIC 2025 (European Identity and Cloud Conference, 2025-05 開催) のフォローアップ、および各 WG の Implementer's Draft 投票関連の発信を進めていた。MODRNA WG として 6 月中に直接発信した openid.net 記事は確認できなかった。

### CAMARA Identity & Consent WG との関連

OpenID Foundation は 2023 年 11 月に Linux Foundation の CAMARA プロジェクトに Associate Member として参加しており、CAMARA Identity & Consent WG では FAPI / CIBA を含む OpenID 仕様の MNO API 適用が継続的に議論されている。Axel Nennker が 6 月 3 日に言及した GSMA ASAC / TS.43 の議論は CAMARA とも問題領域が重なるが、6 月中に MODRNA WG として CAMARA との合同セッションを開いた記録は公開情報からは確認できない。

### Authenticate 2025 / IIW 41 (2025 年 10 月) 準備期

10 月開催予定の Authenticate 2025 (FIDO Alliance, 2025-10-13〜15 Carlsbad)、IIW 41 (2025-10-21〜23 Mountain View) はいずれも MODRNA 関連トピック (CIBA / MNO 認証 / アグリゲータ問題) と親和性が高いカンファレンスであるが、6 月時点で MODRNA WG として登壇・参加に関する公式アナウンスは ML / openid.net 上に確認できなかった。

## 7. 今後の予定 (2025 年 6 月末時点の視点)

公開情報から推測される 7 月以降の継続活動:

- **隔週火曜日 2pm UTC** の定例コール: 7 月 1 日・7 月 15 日・7 月 29 日が次回候補 (ただし夏季休暇シーズンの影響で開催が間引かれる可能性あり)
- **Issue #215 のクローズ確定**: 6 月 17 日コール時点で「反対意見なければクローズ」予告が満了するため、6 月 17 日コール以降の Issue Tracker 上で正式にクローズされる見込み。Bitbucket Issue Tracker が外部から不可視のため最終ステータスは別途確認が必要
- **Issue #220 / #221 の対応**: WG ドキュメンテーション (Overview / Spec ページの Resources) の更新作業が事務的に進む見込み
- **GSMA ASAC / TS.43 動向のフォロー**: Axel Nennker が指摘したアグリゲータ経由のトークンルーティング論点について、GSMA から OpenID Foundation への正式な相談・連携要請が来た場合の受け皿の検討
- **Android OS API 動向のウォッチ**: Android issue tracker 上の feature request (Issue 308240647) で「キャリアの OpenID Provider 識別」が OS レベルでサポートされるか否か。これが実現すれば MODRNA Discovery Profile 等の前提が大きく動く
- **Implementer's Draft 群の状態維持**: Authentication Profile ID1、Account Porting ID1、User Questioning API ID2 はいずれも次版改訂の公式アナウンスがなく、現行ステータスを維持

なお、結果的に MODRNA WG の対外可視な公開活動は 6 月 17 日のアジェンダ投稿を最後に途絶え、7 月は ML 投稿ゼロ、8 月は 8 月 12 日コールキャンセル通知 1 件のみ、9 月は完全静寂月へと移行することになる。
