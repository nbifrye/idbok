# OpenID Foundation MODRNA WG 活動レポート (2026年1月)

> 執筆日: 2026-04-19。本記事は 2026年1月 の活動を遡及的にまとめたものです。

## 1. 概要

MODRNA (Mobile Operator Discovery, Registration & autheNticAtion) WG は、モバイルネットワーク事業者 (MNO) がアイデンティティサービスをリライングパーティに提供する際に適した OpenID Connect プロファイルを開発する OpenID Foundation のワーキンググループです。GSMA との協力のもと、Mobile Connect エコシステムのサポートを主目的として設立されました。CIBA (Client-Initiated Backchannel Authentication) の生みの親であり、自動車アイデンティティ (AiD) や RCS といった新領域でも GSMA・3GPP との連携を継続しています。

2026年1月については、メーリングリストアーカイブを直接確認したところ、対象期間に投稿されたメッセージが存在しないことを確認しました。2025年12月29日週（Week of Mon 20251229）のアーカイブに記録された最後の投稿はミーティングキャンセル通知（2025-12-30 Bjorn Hjelm）であり、その次のエントリは 2026年3月30日週（Week of Mon 20260330）まで存在しません。MODRNA WG はミーティング議事録が非公開であり、仕様リポジトリも GitHub 上には存在しないため、2026年1月については公開記録を確認できなかった月となります。

## 3. 公開記録が確認できなかった項目（ミーティング・ML・GitHub）

MODRNA WG のミーティング議事録は非公開です。以下の一次情報源を調査しましたが、2026年1月の活動記録を確認できませんでした。

### メーリングリスト

- 対象アーカイブ: `https://lists.openid.net/pipermail/openid-specs-mobile-profile/`
- 結果: アーカイブのトップページを取得し、全週のインデックスを確認した。2025年12月29日週（Week of Mon 20251229）の次のエントリが 2026年3月30日週（Week of Mon 20260330）であり、2026年1月中に `openid-specs-mobile-profile` に投稿されたメッセージは存在しない。

### GitHub

- SKILL.md に登録されているリポジトリ URL `https://github.com/openid/MODRNA` は 404 を返した。MODRNA WG の仕様リポジトリは Bitbucket（`https://bitbucket.org/openid/mobile/`）に置かれており、GitHub での公開活動は確認できなかった。

### まとめ

上記の調査を踏まえ、2026年1月の MODRNA WG に関する公開活動記録は存在しなかった（ML 投稿ゼロを実確認）。MODRNA は従来から活動の表面化が少ない WG であり、2026年1月は実質的な公開活動がなかった月と判断される。なお WG 定例コールは毎週火曜日（隔週）に開催されているが（UTC 14:00、PDT 7:00）、議事録は非公開のため内容は不明である。
