# OpenID Foundation MODRNA WG 活動レポート (2025年11月)

> 執筆日: 2026-04-25。本記事は 2025年11月 の活動を遡及的にまとめたものです。

## 1. 概要

MODRNA (Mobile Operator Discovery, Registration & autheNticAtion) WG は、モバイルネットワーク事業者 (MNO) が OpenID Connect プロファイルを通じてアイデンティティサービスをリライングパーティに提供するための仕様を策定する OpenID Foundation のワーキンググループである。GSMA との協力のもと Mobile Connect エコシステムを支え、CIBA (Client-Initiated Backchannel Authentication) の原形を生み出した WG としても知られる。

2025年11月の MODRNA WG の公開活動は、Bjorn Hjelm（共同議長）による **11月4日の定例コール中止通知** の1本のみであった。中止理由は IETF 124 Montreal（2025年11月1日〜7日）との重複である。11月に新規仕様改訂・パブリックレビュー告知・投票通知は確認できず、メーリングリストおよび公開ニュースは事実上静止していた。

前月（10月）も10月21日コールがキャンセルされており、10月〜11月にかけての2か月間は公開活動が極めて希薄な期間であった。次に公開記録が残るミーティングは [2025年12月16日](./2025-12.md) まで間隔が空いている。

## 2. 公開された仕様・ドラフト改訂

2025年11月に MODRNA WG が発行したパブリックレビュー告知・投票通知・エディターズドラフト改訂は、公開情報から確認できなかった。`openid.net/specs/` および ML アーカイブを調査した結果、新規ドラフト番号の変遷は確認されなかった。

MODRNA WG が長期的に扱っている仕様群は以下の通り（いずれもステータスに11月中の変動なし）:

## 3. ミーティングと議論

MODRNA WG は **毎2週火曜 UTC 14:00（PDT 7:00〜8:00）** に定例コールを開催する運営方針である（12月レポート時点で確認済み）。この隔週サイクルを2025年11月に当てはめると、想定される開催日は以下の2日:

| 日付       | 状況                       | 根拠                                                     |
| ---------- | -------------------------- | -------------------------------------------------------- |
| 2025-11-04 | **中止**                   | Bjorn Hjelm から ML へ当日通知。理由は IETF 124 Montreal |
| 2025-11-18 | 公開記録なし（開催は不明） | ML にアジェンダ・キャンセル通知いずれも存在せず          |

### 11月4日コール中止

Bjorn Hjelm が 2025-11-04 14:20 UTC（コール予定時刻直前）にキャンセル通知をメーリングリストに投稿した。本文は非常に簡潔で:

> today's MODRNA WG call is been canceled. Enjoy the IETF meeting for those attending.
> — Bjorn Hjelm, 2025-11-04

複数の MODRNA メンバー（MNO 業界・キャリアサービスプロバイダ・GSMA 関連者など）は IETF Montreal 出張と重複しており、定足数確保が困難であったと推測される。件名に **「REMINDER」** が付いていることから、おそらくカレンダー招待の更新（キャンセル）も別途送信された上での念のための再通知であった。

### 11月18日コール（公開記録なし）

隔週サイクルに従えば 2025-11-18 に次回コールが予定されていたはずだが、当該週（Week of Mon 2025-11-17）の pipermail 週次インデックスは公開されておらず、該当週の ML 投稿は **ゼロ件** である。アジェンダ送付もキャンセル通知も公開されていないため、以下のいずれかに該当すると推測される:

1. コールは実施されたが、アジェンダがメーリングリスト経由ではなく非公開チャネル（WG メンバー向け直接配信・GSMA 内部調整）で共有された
2. コールが実施されたが、メーリングリストへの事前告知が省略された
3. コールが静かに中止された（ML 通知なし）

議事録は MODRNA WG では伝統的に非公開（`non-public`）であるため、どのケースであったかは公開情報からは判定できない。

### 前月（10月）からの連続性

前月 10月21日のコールも Bjorn Hjelm によりキャンセルされており（`Week-of-Mon-20251020` 内の2件の ML 投稿で確認）、10月下旬から11月にかけて MODRNA WG の公開活動は継続的に低調であった。この期間は後続月（12月）の活動準備期と位置づけられる可能性があるが、準備内容は公開されていない。

## 5. GitHub 上の議論

MODRNA WG の仕様リポジトリは Bitbucket（`https://bitbucket.org/openid/mobile/`）に配置されている。`github.com/openid/` 配下に MODRNA 専用リポジトリは存在しない。

Bitbucket Cloud は JavaScript レンダリングを前提とした SPA であるため、公開 Web クローラ経由では Issue/PR 本文の閲覧が難しく、2025年11月分のコミット・Issue・PR 活動については公開手段では確認できなかった。Bitbucket Cloud Issues/Wiki は 2026年8月20日に Atlassian により削除予定であり、MODRNA WG としての移行先（GitHub 等）は2025年11月時点では公表されていない。

## 6. 関連イベント

### IETF 124 Montreal (2025-11-01 〜 2025-11-07)

カナダ・モントリオールで開催された IETF 第124回ミーティング。OAuth WG・GNAP WG 等のアイデンティティ関連 WG が併催された。MODRNA WG の11月4日コール中止の直接的な理由としてメンバーの参加が挙げられており、MNO 業界とキャリアサービス関係者の一部が参加していたことが示唆される。ただし MODRNA WG として公式にセッションを持った記録はない。

他に MODRNA WG が明示的に関与したカンファレンスや外部イベントについては、公開記録から確認できなかった。

## 7. 今後の予定（2025年11月末時点の視点）

2025年11月末時点で、公開情報からは以下の推測のみが可能であった:

- 隔週火曜 UTC 14:00 の定例コール継続（次回想定は12月2日だが、実際には [12月16日](./2025-12.md) まで公開記録のギャップが続く）
- Implementer's Draft 仕様（MODRNA Authentication Profile・Account Porting・User Questioning API）の継続的なドラフト改訂作業
- OpenID Certification for MODRNA の動向（12月16日アジェンダに議題として登場する）
- GSMA との連携（Mobile Connect・RCS 関連）
