# OpenID Foundation MODRNA WG 活動レポート (2025年8月)

> 執筆日: 2026-04-28（遡及執筆）

## 1. 概要

MODRNA WG (Mobile Operator Discovery, Registration, & autheNticAtion Working Group) は、モバイルネットワークオペレータ (MNO) が OpenID Connect / OAuth 2.0 をベースにアイデンティティサービスを提供する際の相互運用プロファイルを策定するワーキンググループである。共同議長は Bjorn Hjelm と John Bradley (Yubico) の 2 名で、定例コールは隔週火曜日 2pm UTC (7am PDT / 4pm CEST) に GoToMeeting (Access Code 927-253-461) で開催される運用となっている。仕様ソースは Bitbucket (`bitbucket.org/openid/mobile/`) で歴史的に管理されており、議事録は non-public 運用である。

2025 年 8 月の MODRNA WG は、`openid-specs-mobile-profile` メーリングリストの公開アーカイブ上で **8 月 12 日のコールキャンセル通知 1 件のみ** という極めて静かな月であった。MODRNA ML のアーカイブは週次インデックス形式で提供されているが、8 月分でアーカイブインデックスが生成されているのは Week-of-Mon-20250811 のみであり、8 月 4 日週・8 月 18 日週・8 月 25 日週はインデックスファイル自体が存在しない。本月は技術スレッドや仕様改訂アナウンスが ML に投稿されず、MODRNA WG の前月（6 月）の Issue 議論を踏まえて夏季のサイレント期に入っていく過渡期に位置する。なお、翌 9 月の ML 公開投稿はゼロとなり、8 月 12 日のキャンセル通知から 10 月 9 日の OIDF 事務局アナウンスまで MODRNA ML には公開投稿が一切流れない長期サイレント期間が始まる。

## 2. 公開された仕様・ドラフト改訂

2025 年 8 月中に openid.net/specs 配下で新規に公開された MODRNA 仕様ドラフトは確認できなかった。MODRNA WG の主要ドラフト群の状態 (8 月末時点) は以下のとおりで、これは前月および翌月と同一である:

| 仕様                                                              | ステータス               |
| ----------------------------------------------------------------- | ------------------------ |
| OpenID Connect Client Initiated Backchannel Authentication – Core | Final                    |
| OpenID Connect MODRNA Authentication Profile                      | Implementer's Draft 1    |
| OpenID Connect Account Porting                                    | Implementer's Draft 1    |
| OpenID Connect User Questioning API                               | Implementer's Draft 2    |
| OpenID Connect MODRNA Discovery Profile                           | Working Draft            |
| OpenID Connect MODRNA Registration Profile                        | Working Draft            |
| Client Initiated Backchannel Authentication Profile (MODRNA 版)   | Working Draft (draft-06) |

`openid.net/tag/modrna/` の MODRNA タグ付きアナウンス一覧にも、8 月付の MODRNA 関連ニュース記事は確認できなかった。OIDF 全体としては 2025 年 8 月 15 日〜29 日の期間で複数仕様の投票プロセスが進行していたが、MODRNA WG 仕様はその対象に含まれていない。

## 3. ミーティングと議論

MODRNA WG の議事録は non-public 運用のため、定例コールの議題・参加者・決定事項は公開されていない。8 月の隔週火曜日サイクルから推定される定例コール候補日と公開記録は以下のとおり:

| 日付            | コール | 公開記録                                                                       |
| --------------- | ------ | ------------------------------------------------------------------------------ |
| 2025-08-12 (火) | 定例   | **キャンセル**（Bjorn Hjelm より 2025-08-12 13:03 UTC に ML へリマインダ投稿） |
| 2025-08-26 (火) | 定例   | ML 上に開催・キャンセル通知なし                                                |

8 月 12 日のキャンセルについては、Bjorn Hjelm が ML に投稿したリマインダで「the MODRNA WG call today, Aug. 12, has been canceled」と通告し、本決定は **その前のミーティングで既に議論されていた** ものであることが本文から読み取れる。MODRNA WG では 2025 年 6 月 17 日に Bjorn Hjelm がアジェンダ投稿（Roll Call、Antitrust Statement、Specification Status、OpenID Certification for MODRNA、Issue Tracker、AOB 等の標準項目）を実施しており、6 月 17 日のコールが 8 月 12 日キャンセルを事前合意した直近の有力候補となるが、6 月 17 日コールの議事録自体は non-public のため確証は取れない。

8 月 26 日のコールについては、ML 上に開催通知もキャンセル通知も投稿されておらず、開催実績を公開情報から確定することはできない。MODRNA WG は北米・欧州の参加者が中心であり、8 月後半は米国・欧州ともに夏季休暇シーズンの繁忙期であることから、実質休止状態にあった可能性が高いが、これは推測にとどまる。

議事録が non-public な MODRNA では、本来 ML / GitHub から議論を再構成するのが代替手段となるが、8 月の ML 投稿は事務的なキャンセル通知 1 件のみで技術議論を含まず、Bitbucket 側の Issue / Wiki も外部から確認できないため、本節で実質的な技術議論を記述することはできない。直前の 6 月 3 日週に行われた Issue #215（クローズ提案）、Issue #220（Update MODRNA WG Overview page）、Issue #221（Update MODRNA WG Spec page）の議論が 8 月時点でどのように進んだかは、Bitbucket Issue Tracker が外部から確認できないため不明である。

## 4. メーリングリストの主要スレッド

`openid-specs-mobile-profile` ML のアーカイブは週次インデックス形式で提供されており、2025 年 8 月の週次インデックス生成状況は以下のとおり:

| アーカイブ週         | 投稿数 | 内容                                                                    |
| -------------------- | -----: | ----------------------------------------------------------------------- |
| Week-of-Mon-20250804 |      0 | 週次インデックスなし                                                    |
| Week-of-Mon-20250811 |      1 | Bjorn Hjelm「REMINDER - MODRNA WG Call Canceled」(2025-08-12 13:03 UTC) |
| Week-of-Mon-20250818 |      0 | 週次インデックスなし                                                    |
| Week-of-Mon-20250825 |      0 | 週次インデックスなし                                                    |

唯一のスレッド本文は事務連絡であり技術的な議論を含まないが、MODRNA WG 議事録が non-public な以上、コール開催状況を外部から把握できる数少ない一次情報となる。スレッドの要点は以下のとおり:

- [REMINDER - MODRNA WG Call Canceled](https://lists.openid.net/pipermail/openid-specs-mobile-profile/Week-of-Mon-20250811/001994.html) - 2025-08-12 開始
  - 投稿者: Bjorn Hjelm（共同議長）
  - 内容: 当日 (8 月 12 日) の MODRNA WG コールがキャンセルされたことの再通知。本キャンセルは「直近のミーティングで既に議論されていた」と本文に明記されており、事前合意事項のリマインダとしての位置付け。
  - 参加・反応: ML 上の返信なし。事務連絡のため通常返信は発生しない種類の投稿。
  - 観察: 同日 13:03 UTC に投稿されており、米国東部時間では朝 9 時、欧州中央時間では 15 時にあたる。当日のコール開催予定時刻 (2pm UTC = 14:00 UTC) の約 1 時間前のリマインダであった。

参考までに、8 月を挟む直前直後のアーカイブ状況は以下のとおり:

- [Week-of-Mon-20250616 date index](https://lists.openid.net/pipermail/openid-specs-mobile-profile/Week-of-Mon-20250616/date.html): Bjorn Hjelm「MODRNA WG Agenda」(2025-06-17 14:01 UTC) の 1 件のみ。8 月 12 日キャンセル決定の前提となった 6 月 17 日コールのアジェンダ投稿。
- [Week-of-Mon-20251006 date index](https://lists.openid.net/pipermail/openid-specs-mobile-profile/Week-of-Mon-20251006/date.html): Mike Leszcz「New OpenID Foundation Notes & Recordings Policy」(2025-10-09 13:50 UTC) の 1 件のみ。8 月 12 日のキャンセル通知から実に約 2 ヶ月後となる、MODRNA ML への次の投稿。

8 月のアーカイブから読み取れるのは「事務的なキャンセル通知 1 件のみ」という事実であり、技術スレッドとしての議論はゼロであった。MODRNA WG ではアクティブな月とゼロ投稿の月が混在することが知られており（`/oidf` スキル定義の「データソースの既知の制約」にも明記）、2025 年 8 月は実質的に「8 月 12 日のキャンセル通知のみが残った夏季サイレント月」と位置付けられる。

## 5. GitHub 上の議論

MODRNA WG の仕様ソースは GitHub ではなく Bitbucket Cloud (`bitbucket.org/openid/mobile/`) で管理されている。Bitbucket Cloud の Issue / Wiki は SPA 描画のため外部のクローリングに適さず、本稿の調査範囲では 8 月中の Issue / PR / コミット活動の具体的件数を確認できなかった。

GitHub 側に MODRNA の公式一次リポジトリは存在しない（過去に `github.com/openid/MODRNA` といった誤記が出回ることがあるが、そのようなリポジトリは現存しない）。本サイト（idbok）の `docs/oidf/modrna/index.md` 内に同種の誤リンクが含まれている点は別途修正対象である。

なお Bitbucket Cloud の Issues / Wiki は 2026 年 8 月 20 日に完全削除予定であることが Atlassian から告知されているが、2025 年 8 月時点では Atlassian 側の正式アナウンス前であり、MODRNA WG 内で具体的な GitHub 移行検討が進行していた形跡は公開情報からは確認できない。

## 6. 関連イベント

### 8 月の OIDF 全体投票プロセス

OpenID Foundation の Notice of Vote プロセスとして、2025 年 8 月 15 日から 8 月 29 日にかけて複数の OIDF 仕様についての投票期間が設定されていた。ただし MODRNA WG の主要ドラフト（Authentication Profile / Account Porting / User Questioning API）は今回の投票対象に含まれておらず、MODRNA WG として 8 月の投票プロセスに直接関与する案件はない。

### Authenticate 2025 (2025 年 10 月 13〜15 日) 準備期

FIDO Alliance 主催の年次カンファレンス Authenticate 2025 がカリフォルニア州 Carlsbad で 10 月中旬に予定されており、8 月時点では開催 2 か月前の準備期にあたる。MODRNA 共同議長の Bjorn Hjelm は Authenticate 登壇歴があり、CIBA / MODRNA の業界実装事例が議論される場として MNO 関係者も注視していた時期と推察されるが、MODRNA WG として 8 月中に公式な参加・登壇アナウンスは ML / openid.net 上に確認できなかった。

### IIW 41 (2025 年 10 月 21〜23 日) 準備期

カリフォルニア州 Mountain View の Computer History Museum で 10 月下旬に開催される Internet Identity Workshop。MODRNA 関連トピック（CIBA、MNO 認証、ZTA における MNO の役割）は IIW の常連トピックであるが、8 月の段階では特段のアナウンスは MODRNA ML に流れていない。

### CAMARA Identity & Consent WG との関連

OpenID Foundation は 2023 年に Linux Foundation の CAMARA プロジェクトに参加しており、CAMARA Identity & Consent WG では FAPI / CIBA を含む OpenID 仕様の MNO API 適用が継続的に議論されている。8 月中に MODRNA WG として CAMARA との合同セッションを開いた記録は公開情報からは確認できなかった。

## 7. 今後の予定 (2025 年 8 月末時点の視点)

公開情報からは、MODRNA WG の 9 月以降の明示的な予定は確認できなかった。8 月末時点で推測される継続活動:

- **隔週火曜日 2pm UTC** の定例コール: 9 月 9 日・9 月 23 日が次回候補（ただし夏季休暇の延長で開催されない可能性あり）
- **Implementer's Draft 群の状態維持**: Authentication Profile ID1、Account Porting ID1、User Questioning API ID2 はいずれも次版改訂の公式アナウンスがなく、8 月時点では現行ステータスを維持
- **CIBA Core Final 後のメンテナンス**: Final 公開済み仕様に対する実装フィードバックの ML 受付を継続
- **6 月の Issue 群（#215, #220, #221）の継続フォロー**: Bitbucket Issue Tracker 上での処理は外部から不可視だが、9 月以降の WG コール再開時に進捗確認が見込まれる
- **Authenticate 2025 / IIW 41 への WG メンバー参加**: 10 月のイベント期に一部メンバーがオフラインで議論する見通し

8 月時点の WG 活動の対外可視性は極めて低く、当時の読者にとっては「コールキャンセル通知 1 件以外は完全な沈黙」として認識されていたと言える。続く 9 月にはこの沈黙がさらに深まり、ML 投稿ゼロの完全静寂月へと移行することになる。
