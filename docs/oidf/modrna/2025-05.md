# OpenID Foundation MODRNA WG 活動レポート (2025年5月)

> 執筆日: 2026-04-28（遡及執筆）

## 1. 概要

MODRNA WG (Mobile Operator Discovery, Registration, & autheNticAtion Working Group) は、モバイルネットワークオペレータ (MNO) が OpenID Connect / OAuth 2.0 をベースにアイデンティティサービスを提供する際の相互運用プロファイルを策定するワーキンググループである。共同議長は Bjorn Hjelm と John Bradley (Yubico) の 2 名で、定例コールは隔週火曜日 2pm UTC (7am PDT / 4pm CEST) に開催される運用となっている。仕様ソースは Bitbucket (`bitbucket.org/openid/mobile/src/master/`) で歴史的に管理されており、議事録は non-public 運用である。

2025 年 5 月の MODRNA WG は、`openid-specs-mobile-profile` メーリングリストの公開アーカイブ上で **5 月分の週次インデックスが一切生成されていない** という完全静寂月であった。pipermail 親インデックス (`https://lists.openid.net/pipermail/openid-specs-mobile-profile/`) を参照すると、4 月 21 日週の次に登場するエントリは 6 月 2 日週であり、その間の 4 週 (4 月 28 日週・5 月 5 日週・5 月 12 日週・5 月 19 日週・5 月 26 日週) はいずれもインデックスファイル自体が存在しない。各週次 URL を直接叩くといずれも HTTP 404 を返し、5 月の MODRNA ML 公開投稿は **ゼロ** であったことが確定する。

5 月の MODRNA WG コール候補日 (隔週火曜日サイクル) としては 5 月 6 日・5 月 20 日が該当するが、いずれも ML 上に開催通知もキャンセル通知も投稿されておらず、開催実績を公開情報から確定することはできない。直近で公開アーカイブから推認できる MODRNA ML 動向は、4 月 8 日のコールキャンセル通知 (Bjorn Hjelm より 2 件) と、4 月 23 日に Brian Campbell が `openid-specs-fapi` と `openid-specs-mobile-profile` をクロスポストした FAPI 1.0 Advanced errata 公開アナウンスのみであり、いずれも MODRNA WG として独自の技術議論を含むものではない。続く 6 月 3 日には Bjorn Hjelm が Issue #215 (Android Carrier OpenID API) のクローズ提案や Issue #220 / #221 の起票通知を ML に流して活動が復調するため、本月はその直前の沈黙期間にあたる。

## 2. 公開された仕様・ドラフト改訂

2025 年 5 月中に openid.net/specs 配下で新規に公開された MODRNA 仕様ドラフトは確認できなかった。MODRNA WG の主要ドラフト群の状態 (5 月末時点) は以下のとおりで、これは 6 月末・7 月末・8 月末時点と同一である:

| 仕様                                                              | ステータス            |
| ----------------------------------------------------------------- | --------------------- |
| OpenID Connect Client Initiated Backchannel Authentication – Core | Final                 |
| OpenID Connect MODRNA Authentication Profile                      | Implementer's Draft 1 |
| OpenID Connect Account Porting                                    | Implementer's Draft 1 |
| OpenID Connect User Questioning API                               | Implementer's Draft 2 |
| OpenID Connect MODRNA Discovery Profile                           | Working Draft         |
| OpenID Connect MODRNA Registration Profile                        | Working Draft         |
| Client Initiated Backchannel Authentication Profile (MODRNA 版)   | Working Draft         |

`openid.net/tag/modrna/` の MODRNA タグ付きアナウンス一覧にも 5 月付の MODRNA 関連記事は確認できなかった。直近で MODRNA タグが付いた openid.net 記事は CIBA Core Final 化アナウンス (2021 年)、User Questioning API 第 2 ID 承認アナウンス (2020 年)、CAMARA 連携アナウンス (2023 年 11 月) 等の過年度のものに留まり、2025 年 5 月時点では MODRNA WG として新たな投票通知・公開アナウンスは発出されていない。

## 3. ミーティングと議論

MODRNA WG の議事録は non-public 運用のため、定例コールの議題・参加者・決定事項は公開されていない。5 月の隔週火曜日サイクルから推定される定例コール候補日と公開記録は以下のとおり:

| 日付            | コール | 公開記録                        |
| --------------- | ------ | ------------------------------- |
| 2025-05-06 (火) | 定例   | ML 上に開催・キャンセル通知なし |
| 2025-05-20 (火) | 定例   | ML 上に開催・キャンセル通知なし |

MODRNA WG では Bjorn Hjelm がコール中止時に ML へリマインダを投稿する運用が確認されており、実際 4 月 8 日コールについては「REMINDER - MODRNA WG Call Canceled」と GoToMeeting イベントのキャンセル通知の 2 通が ML に流れている。しかし 5 月の 2 つのコール候補日についてはそうしたキャンセル通知も開催通知も存在しないため、(1) 静かに開催されたが議事録 non-public のため記録が表に出ていない、(2) 4 月 8 日キャンセルからの実質休止が継続していた、(3) 開催されたが ML への事前事後通知が省略された、のいずれかと推察されるが、公開記録から判定する材料はない。

議事録が non-public な MODRNA では、本来 ML / GitHub から議論を再構成するのが代替手段となるが、5 月の ML が完全にゼロ投稿であり、Bitbucket 側の Issue / Wiki も外部から確認できないため、本節で実質的な技術議論を記述することはできない。直後の 6 月 3 日コールで Bjorn Hjelm が Issue #215 (Android Carrier OpenID API) のクローズ提案、Issue #220 (Update MODRNA WG Overview page)、Issue #221 (Update MODRNA WG Spec page) を相次いで ML に流すことになるが、これらの起票・クローズ判断が 5 月のいずれかのタイミングで内部議論されていたかは公開情報からは確認できない。

## 4. メーリングリストの主要スレッド

`openid-specs-mobile-profile` ML のアーカイブは週次インデックス形式で提供されており、2025 年 5 月の週次インデックス生成状況は以下のとおり:

| Week-of-Mon-20250505 |      0 | 週次インデックスなし (HTTP 404) |

| Week-of-Mon-20250526 |      0 | 週次インデックスなし (HTTP 404) |

5 月の MODRNA ML 投稿は事務連絡を含めて完全にゼロであった。MODRNA WG ではアクティブな月とゼロ投稿の月が混在することが知られており (`/oidf` スキル定義の「データソースの既知の制約」にも明記)、2025 年 5 月はその「ゼロ投稿月」に該当する。

参考までに、5 月を挟む直前直後のアーカイブ状況は以下のとおり:

- [Week-of-Mon-20250407 date index](https://lists.openid.net/pipermail/openid-specs-mobile-profile/Week-of-Mon-20250407/date.html): Bjorn Hjelm「REMINDER - MODRNA WG Call Canceled」(2025-04-08 13:29 UTC) と「Canceled event: MODRNA WG @ Tue Apr 8, 2025 7am - 8am (PDT)」(2025-04-08 13:30 UTC) の 2 件。4 月 8 日の WG コールのキャンセル通知と GoToMeeting カレンダー連動の自動キャンセル通知。
- [Week-of-Mon-20250421 date index](https://lists.openid.net/pipermail/openid-specs-mobile-profile/Week-of-Mon-20250421/date.html): Brian Campbell「\[Openid-specs-fapi\] Publishing FAPI 1.0 advanced errata set to openid.net/specs/」(2025-04-23 12:29 UTC) の 1 件のみ。`openid-specs-fapi` との Cc クロスポストで、FAPI 1.0 Advanced errata の openid.net/specs 配下への公開アナウンス。MODRNA WG 固有の議論ではなく、CIBA / FAPI 連携を意識した情報共有。
- [Week-of-Mon-20250602 date index](https://lists.openid.net/pipermail/openid-specs-mobile-profile/Week-of-Mon-20250602/date.html): 6 月 3 日に集中した 6 件のスレッド (Bjorn Hjelm のアジェンダ 1 件、Issue #215 関連 3 件、Issue #220 起票 1 件、Issue #221 起票 1 件)。MODRNA WG の対外可視な活動が 5 月の沈黙を経て復調する時点にあたる。

5 月のアーカイブから読み取れるのは「週次インデックスそのものが存在せず、ML 投稿はゼロ」という事実のみで、技術スレッドとしての議論はない。4 月 23 日の FAPI errata クロスポストから 6 月 3 日のアジェンダ投稿までの約 6 週間、MODRNA ML には公開投稿が一切ない長期サイレント期間の中盤に位置する。

## 5. GitHub 上の議論

MODRNA WG の仕様ソースは GitHub ではなく Bitbucket Cloud (`bitbucket.org/openid/mobile/src/master/`) で管理されている。Bitbucket Cloud の Issue / Wiki は SPA 描画のため外部のクローリングに適さず、本稿の調査範囲では 5 月中の Issue / PR / コミット活動の具体的件数を確認できなかった。

GitHub 側に MODRNA の公式一次リポジトリは存在しない (`github.com/openid/MODRNA` といった誤記が出回ることがあるが、そのようなリポジトリは現存しない)。本サイト (idbok) の `docs/oidf/modrna/index.md` 内に同種の誤リンクが含まれている点は別途修正対象である。

なお Bitbucket Cloud の Issues / Wiki は 2026 年 8 月 20 日に完全削除予定であることが Atlassian から告知されることになるが、2025 年 5 月時点では Atlassian 側の正式アナウンス前であり、MODRNA WG 内で具体的な GitHub 移行検討が進行していた形跡は公開情報からは確認できない。

直後の 6 月 3 日コールで起票・クローズ提案される Issue 群 (#215 / #220 / #221) について、5 月時点で Bitbucket 側に下書きやコメントの動きがあったか否かは、Bitbucket Issue Tracker が外部から確認できないため判明していない。

## 6. 関連イベント

### 5 月の OIDF 全体動向

MODRNA WG の領域外ではあるが、OpenID Foundation は 2025 年 5 月に欧州での年次カンファレンス European Identity and Cloud Conference (EIC 2025, 2025-05 開催、ドイツ Berlin) のフォローアップ期にあたり、各 WG の発表・パネルが現地で展開されていた時期である。MODRNA WG として 5 月中に EIC 関連で公式に発信された openid.net 記事は確認できなかった。

### CAMARA Identity & Consent WG との関連

OpenID Foundation は 2023 年 11 月に Linux Foundation の CAMARA プロジェクトに Associate Member として参加しており、CAMARA Identity & Consent WG では FAPI / CIBA を含む OpenID 仕様の MNO API 適用が継続的に議論されている。Bjorn Hjelm は OIDF の CAMARA Liaison Officer も兼務しているが、5 月中に MODRNA WG として CAMARA との合同セッションを開いた記録や、MODRNA ML への CAMARA 進捗共有は公開情報からは確認できない。

### FAPI errata クロスポストの背景

4 月 23 日に Brian Campbell が `openid-specs-fapi` と `openid-specs-mobile-profile` の双方に流した FAPI 1.0 Advanced errata 公開アナウンスは、MODRNA WG が CIBA を起点として FAPI と仕様面で接続している関係性を反映している。5 月中には MODRNA WG 側からの追加反応はなく、FAPI errata に対する MODRNA 視点での技術検討が 5 月の ML 上で展開された形跡もない。

## 7. 今後の予定 (2025 年 5 月末時点の視点)

公開情報からは、MODRNA WG の 6 月以降の明示的な予定は確認できなかった。5 月末時点で推測される継続活動:

- **隔週火曜日 2pm UTC** の定例コール: 6 月 3 日・6 月 17 日が次回候補。EIC 2025 のフォローアップ期を抜け、北半球の夏季休暇シーズン入り直前のタイミング
- **Implementer's Draft 群の状態維持**: Authentication Profile ID1、Account Porting ID1、User Questioning API ID2 はいずれも次版改訂の公式アナウンスがなく、5 月末時点では現行ステータスを維持
- **CIBA Core Final 後のメンテナンス**: Final 公開済み仕様に対する実装フィードバックの ML 受付を継続。FAPI 1.0 Advanced errata 公開を受けて、CIBA / FAPI 連携領域での実装報告が ML に流れる可能性
- **Issue Tracker の継続レビュー**: MODRNA WG 標準アジェンダに含まれる `Issue Tracker` 項目のレビューが 6 月以降のコールで再開される見込み
- **Authenticate 2025 / IIW 41 (2025 年 10 月)**: 開催 5 か月前にあたり、登壇候補者の検討が水面下で始まる時期

5 月時点の WG 活動の対外可視性は極めて低く、当時の読者にとっては「4 月 8 日コールキャンセル後、長期サイレント期間が続く沈黙月」として認識されていたと言える。続く 6 月には Bjorn Hjelm 主導で Issue #215 のクローズ提案や Issue #220 / #221 の起票が ML に流れて一時的に活動が復調するが、その後 7 月の ML ゼロ投稿、8 月のキャンセル通知 1 件のみ、9 月の完全静寂と、夏季サイレント期へ移行していくことになる。
