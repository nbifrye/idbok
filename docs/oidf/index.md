# OpenID Foundation 月次レポート

OpenID Foundation の各 Working Group (WG) / Community Group (CG) の活動を **月次粒度** でまとめた詳細レポート集です。

メーリングリスト・ミーティング議事録・GitHub issues/PRs から読み取れる「どのような議論が行われ、誰がどの立場を取り、どの論点が対立したか」という一次情報の再構成を中心に据えています。

- [AB/Connect WG](/oidf/connect/) — [openid.net/wg/connect](https://openid.net/wg/connect/)
- [AuthZEN WG](/oidf/authzen/) — [openid.net/wg/authzen](https://openid.net/wg/authzen/)
- [Digital Credentials Protocols WG](/oidf/dcp/) — [openid.net/wg/digital-credentials-protocols](https://openid.net/wg/digital-credentials-protocols/)
- [eKYC & Identity Assurance WG](/oidf/ekyc-ida/) — [openid.net/wg/ekyc-ida](https://openid.net/wg/ekyc-ida/)

- [iGov WG](/oidf/igov/) — [openid.net/wg/igov](https://openid.net/wg/igov/)
- [IPSIE WG](/oidf/ipsie/) — [openid.net/wg/ipsie](https://openid.net/wg/ipsie/)
- [MODRNA WG](/oidf/modrna/) — [openid.net/wg/modrna](https://openid.net/wg/modrna/)
