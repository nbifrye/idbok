# OpenID Foundation ADT CG 活動レポート (2025年9月)

> 執筆日: 2026-04-25（遡及執筆）

## 1. 概要

Australian Digital Trust Community Group（ADT CG）は、オーストラリアにおけるデジタル ID・デジタルトラストエコシステムを推進するために設置された OpenID Foundation の Community Group である。共同議長は Dima Postnikov、Victoria Richardson、Dave Hyland、Brad Carr、Olaf Grewe の5名。定例ミーティングは隔週月曜日 17:00 AEST（Eastern Australia Time）に Zoom で開催される。Trust Framework Analysis サブグループも同様に隔週月曜同時刻に別開催されている。

2025年9月の ADT CG は、活動の中心が **オーストラリア政府の Productivity Commission（生産性委員会）向けの提言書（submission）** 取りまとめにあった月であった。提出期限（10月15日）を前に、9月前半は Olaf Grewe がドラフトを作成し、9月後半には最終化して正式提出された。並行して9月18日にシドニーで ADT CG 初の対面ラウンドテーブル「Age Assurance Roundtable」を開催し、Age Check Certification Scheme の Tony Allen と Age Verification Providers Association（AVPA）の Iain Corby を迎えた。Trust Framework Analysis サブグループは AGDIS（Australian Government Digital ID System）と国際的なトラストフレームワーク（eIDAS 2、NIST 800-63、UK DIATF、Canada DIACC、Singpass、BankID 等）のマッピング作業を継続した。

メーリングリストの投稿数は5件といずれも David Hyland による事務連絡（アジェンダ配布・ラウンドテーブル告知）に限られたが、GitHub 上に記録された5本の議事録（メイングループ2本・TFA サブグループ3本）から、ADT CG が Australia 政府のデジタル ID 政策形成に直接インプットする市民ワーキンググループとして機能している様子が読み取れる。

## 2. 公開された仕様・ドラフト改訂

ADT CG はコミュニティグループであり、OpenID の技術仕様そのものを策定する Working Group ではない。主な成果物は以下のカテゴリに整理されている:

- **Productivity Commission 向け Submission**: 2025年10月15日提出予定（9月末に Olaf Grewe が正式提出済み）
- **Trust Framework Analysis**: AGDIS と国際トラストフレームワークの対比マッピング（継続進行中）
- **Age Assurance**: 要件分析とオーストラリアにおける年齢確認ルールへの対応（Jacob Oberman が問題定義を主導）
- **Digital Estate / Death & Digital Identity**: 別サブグループにて議論継続（本レポート対象外）

9月中に OpenID Foundation 公式仕様としての新規ドラフトリリース・改訂は確認できなかった。ADT CG の成果物は OpenID の spec ではなく、政府・業界向けの提言書・分析文書である。

### 3.1 9月1日 Trust Framework Analysis サブグループ

参加者: Derek Munneke、David Hyland、Linden Dawson、Olaf Grewe、Brad Carr、Kate Virgona、Jo Spencer、Jacob Oberman、Dima Postnikov、Andres Olave、Jan Vereecken、Michael Fraser。

Productivity Commission 中間報告への応答方針が主議題。主要論点:

- **政府機関間の相互承認**: データガバナンスにおいて各政府機関が互いの枠組みを正式に承認する必要性
- **クロスボーダーの相互運用性**: プライバシー観点だけでなく「データの相互運用性」と既存イニシアチブとの整合性を含めて検討すべき
- **データの真正性（provenance）とデータ保護の切り分け**: C2PA 標準が参照情報として挙がり、真正性の議論をデータ保護から独立させる方向で合意
- **Right to be Forgotten への応答**: データ保護テーマの中で独立の節として扱うことを決定

アクションアイテム: (1) 次回会合までに各テーマの first-pass 応答を完成、(2) Dima が Austroads（オーストラリア道路運輸局協議会）の trust framework の扱いを確認、(3) Linden が要求された用語定義を提出。

### 3.4 9月22日 ADT CG メイン会合

参加者（11名）: Victoria Richardson、Olaf Grewe、John Scullen、Dave Hyland、Victor Lu、Jacob Oberman、Dima Postnikov、Brad Carr、Stefan Charsley、Kate Virgona、Derek Munneke。

主要議題:

- **Productivity Commission 提言の最終化・提出**: Olaf が提言書を Productivity Commission に正式提出、Commission から受領確認済み。ADT CG 公式ブログでの紹介記事を併せて準備
- **Age Assurance 技術プレゼンテーション**: Tony Allen（ACCS）および Iain Corby（AVPA）による Age Assurance に関する発表。Age Assurance と Identity Assurance の違いを明確化し、米国で施行が進む年齢確認規制が普及を牽引している点、ISO 27566 が「pretty light」（内容が軽い）でオンボーディングと認定ガイダンスに空白が残る点を指摘
- **参加型懇話会開催の報告**: (a) Identity Week（小売事業者・カジノ運営者が出席）、(b) ID Match（政府代表者が登壇、改正 AML/CTF 規制が主要話題）、(c) AAF（Australian Access Federation）主催の大学向けデジタル ID イベント
- **Slack アクセス方針**: OIDF Board の決定により、Slack への参加には participation agreement の署名は不要となったことを事務的に確認

アクションアイテム: (1) Dave が Ralph Bragg を招いてデータシェアリングエコシステムの議論を設定、(2) Kate が Brad と連携して Age Assurance レポートおよび LinkedIn コンテンツを調整、(3) Olaf が Linden に Identity Week Washington の知見プレゼンテーションを依頼、(4) 全員が Digital ID System rules consultation を確認し submission 提出の是非を検討、(5) Jacob が Age Assurance Slack チャネル向けに問題定義ドラフトを作成。

### 3.5 9月29日 Trust Framework Analysis サブグループ

参加者（8名）: Olaf Grewe、Dave Hyland、Brad Carr、Eric Jiang、Gareth Narinesingh、Jacob Oberman、Linden Dawson、Stefan Charsley。

主要議題:

- **AGDIS × SIDI（SIDI Hub）マッピング**: Dave が AGDIS を SIDI（Sustainable and Interoperable Digital Identity）フレームワークにマップする分析を提示。Gareth が Electronic Attestation と Qualified Electronic Attestation の区別を説明（UK の「政府規定本人確認保証レベル」に関連する電子取引・詐欺軽減文脈）
- **OIDF ファンディング**: Gareth が directed funding（OIDF メンバーシップを前提とする）の要件を報告。2つの核心要件は (a) コミュニティへの便益、(b) アクティブなメンバーシップ
- **"no phone home" プライバシー構想**: Eric から、モバイル運転免許証のオンライン検証でサーバへの照会を廃止する構想が共有される。Stefan が「サーバ取得要件の排除」に向けた取り組みを補足
- **Age Assurance 進捗**: Jacob が要件整理の進捗を報告、Linden が関連メディア報道を紹介
- **公開相談への応答方針**: Digital ID Rules Consultation および Prepaid mobile services verification with Digital ID プロポーザルの2件が議題化。参加メンバー間で「ADT CG として公式見解を出すべきか」について議論があり、最終的には「強く推す立場は取らない」と決議

アクションアイテム: (1) Chairs が公開相談への submission 有無を議論、(2) Dave が AGDIS を trust framework スプレッドシートへマッピング継続、(3) Dima が ConnectID 向け ChatGPT 作業を完了、(4) Jan が日本ユースケース比較を進行、(5) Andres が10月中旬に Velocity Network 詳細プレゼン、(6) Dave が今後のアジェンダを workshop playback とユースケースワークで構成。

## 6. 関連イベント

### ADT Age Assurance Roundtable（2025年9月18日、シドニー）

ADT CG 初の対面ラウンドテーブルイベント。Age Check Certification Scheme ディレクター Tony Allen が登壇。ADT CG としては Age Assurance を Identity Assurance から概念的に分離する立場を確認する機会となった。9月22日会合では Tony Allen と Iain Corby（AVPA）が参加し、ラウンドテーブルの成果を詳説した。

### Digital Identity Week（2025年9月9〜10日）

オーストラリアの識別・認証関連年次カンファレンス。Identity Week Washington 等の関連海外イベントと連動した情報交換の場として ADT CG メンバーも参加。

### ID Match（2025年9月16〜17日）

政府代表者も参加し、改正 AML/CTF（Anti-Money Laundering / Counter-Terrorism Financing）規制が中心話題となったイベント。Stefan Charsley らが参加し、議事録に報告。

### AAF 主催 大学向けデジタル ID イベント

Australian Access Federation が主催した高等教育機関向けイベント。研究教育セクターの identity management ニーズに焦点が当たった。

### Productivity Commission 提言書 提出（2025年9月下旬）

ADT CG として取りまとめた提言書を Olaf Grewe が Productivity Commission に正式提出。受領確認取得済み。オーストラリア政府のデジタル ID 政策形成に対する市民ワーキンググループとしての直接的なインプットとなった。
