# OpenID Foundation Ecosystem Support CG 活動レポート (2026年2月)

> 執筆日: 2026-04-17（遡及執筆）

## 1. 概要

**Ecosystem Support CG (ESCG)** は、OpenID Foundation が展開するエコシステム全体の支援活動を担うコミュニティグループである。Open Banking / オープンファイナンス・デジタルアイデンティティ領域の実装者や規制当局との連携促進、OIDF 加盟組織へのアウトリーチ、各国・地域での OIDF 認定プログラムの普及支援などを主な活動領域とする。仕様策定そのものはスコープ外とし、エコシステムごとの実装ベストプラクティスや「Open Banking Reference Technical Architecture and Best Practices」のようなガイダンス文書の整備、エコシステム間の経験共有を主眼とする。共同チェアは Dima Postnikov、Ralph Bragg、Mark Verstege の3名が務め、月次ミーティングを EU 時間帯と Pacific 時間帯で交互に開催している。

2026年2月は ESCG の設立目的に直結する大きなマイルストーンとして、**2月26日に OpenID Foundation による自己適合試験サービス（Self-Certification）が正式ローンチ**された。対象仕様は OpenID4VP 1.0・OpenID4VCI 1.0・HAIP 1.0 の3仕様であり、ESCG が推進してきた「エコシステム横断の相互運用性確保」の取り組みが具体的な認証基盤として結実した月となった。

ESCG 自体の公開された記録（メーリングリストアーカイブ・GitHub・議事録）については、2025年9月以降の ML 投稿が確認されない状況が継続しており、2026年2月分についても公開記録は確認できなかった。以下、調査した情報源ごとに結果を記録する。

## 2. 公開された仕様・ドラフト改訂

### Self-Certification サービス正式ローンチ（2026年2月26日）

ESCG の活動目標と密接に関連するイベントとして、OpenID Foundation は **2026年2月26日** に以下の3仕様を対象とした自己適合試験サービスを正式にローンチした。

| 仕様                                                   | バージョン |
| ------------------------------------------------------ | ---------- |
| OpenID for Verifiable Presentations (OpenID4VP)        | 1.0 Final  |
| OpenID for Verifiable Credential Issuance (OpenID4VCI) | 1.0 Final  |
| High Assurance Interoperability Profile (HAIP)         | 1.0 Final  |

テストツールはオープンソースで無償公開され、OpenID Foundation のサーバー経由またはローカル環境での実行が可能。Self-Certification（自己適合宣言）の料金体系は OIDF 会員向け1仕様あたり700ドル、非会員向け3,500ドルとなっている。

**技術的カバレッジ**:

- Presentation テスト: SD-JWT・mdoc の両フォーマットをサポート
- Issuance テスト: SD-JWT 対応済み、mdoc サポートは同月中に追加予定
- ポジティブ・ネガティブテストを組み合わせ、セキュリティおよび相互運用上のリスクを低減する設計

2025年11月のリモート相互運用イベントでは、Wallet/Verifier ペアで98%、Issuer-Wallet ペアで82%の合格率が確認されており、仕様の成熟度を裏付けている。

OpenID Foundation は、2026年2月に安定した標準規格と適合試験が同時に揃ったことにより、デジタルアイデンティティエコシステムが本番スケールで展開するための基盤が整ったとしている。

### OpenID Federation 1.0 最終仕様承認投票

ESCG の活動範囲とは異なるが、2月の OIDF 全体の動向として重要な出来事が重なった。

- **投票期間**: 2026年2月3日〜17日
- **対象**: OpenID Federation 1.0 Final Specification の承認
- 60日間のパブリックレビュー期間を経て、会員投票が実施された

### OpenID Federation 1.1 パブリックレビュー開始

- **パブリックレビュー開始**: 2026年2月17日
- **レビュー期間終了**: 2026年4月18日
- **投票期間**: 2026年4月20日〜5月4日予定

## 3. ミーティングおよびメーリングリスト・GitHub 上の公開記録

### ミーティング

ESCG は月次ミーティングを概ね4週間ごとに EU 時間帯（月曜 18:00 Sydney 時間 / 9:00 UK 時間）と Pacific 時間帯（金曜 10:00 Sydney 時間）で交互に開催している。2026年2月においても同様のペースで定例会議が開催されたと推定されるが、議事録は non-public であるため内容は確認できない。

標準アジェンダとして把握できているのは（2025年9月のメーリングリスト投稿より）:

1. 新参加者の紹介
2. CG 管理業務
3. イベント情報
4. エコシステム更新情報
5. OIDF メンバーシップリマインダー
6. 一般ディスカッション（アクション、チャーターレビュー、Digital Wallet Reference Technical Architecture、バックログ）
7. AOB（その他事項）

2月開催のミーティングでは、月末に予定されていた Self-Certification ローンチへの対応や、各エコシステムからのフィードバック収集が主要トピックになった可能性が高い。

### メーリングリスト

公開アーカイブ（https://lists.openid.net/pipermail/openid-ecosystem-support/）の月次インデックスを確認したところ、**2026年2月分のアーカイブは存在しない**。確認できた最新のアーカイブは 2025年9月であり、以降の投稿は公開されていない。

このメーリングリストは「private list」であり、メンバー以外にはメンバーリストが公開されない旨が listinfo ページに明記されている。公開アーカイブに残る投稿は会議前アジェンダ通知が中心であり、実質的な議論はミーティング内で行われていると考えられる。

### GitHub

GitHub リポジトリ（https://github.com/openid/cg-ecosystem-support）は 2025年1月2日に作成されたが、2026年2月時点においてもコンテンツは一切追加されておらず、Issue・Pull Request ともに 0 件のままである。

## 4. 関連イベント

### Self-Certification ローンチと ESCG のミッション

2月26日の Self-Certification ローンチは、ESCG が設立当初から推進してきた「エコシステム横断の相互運用性確保」という目標の重要な達成点である。ESCG は90以上の法域でオープンバンキング・オープンデータ・デジタルアイデンティティ施策が並行して進む状況の中で、OIDF 仕様の採用を促進する役割を担っている。現時点で38法域がこれらの仕様を採用しており、EU（EUDIW）、英国、スイス、西バルカン諸国、日本、米国（カリフォルニア DMV・NIST）が含まれる。

OIDF はまた、以下の5機関との MOU（覚書）を締結済みであり、より広範なエコシステム適合サービスの展開基盤が整いつつある:

- BixeLab
- FIDO Alliance
- Fime
- Raidiam
- TrustID Solutions

### Q2 2026 に向けた認定サービス拡大

OIDF 理事会は Q2 2026 に向けて、「Managing Entity」および「Accredited Laboratory」とのパートナーシップモデルによる認定サービス拡大を承認している。この拡張は ESCG がエコシステムオーナーに提供できるサービスの幅を広げるものと位置づけられている。

## 5. 今後の予定（2026年2月末時点）

2026年2月末時点で予定されていた主要動向は以下の通り:

- **OpenID4VCI 1.0 mdoc サポートの Issuance テスト追加**（数週間以内と告知）
- **Q2 2026 認定サービス（Accreditation Services）ローンチ**（パイロットパートナーシップと並行）
- **ESCG 定例ミーティング継続**（3月・EU 会議と Pacific 会議）
- **OpenID Federation 1.1 パブリックレビュー継続**（〜4月18日）
- **OpenID Federation 1.0 最終承認結果の公開**（2月17日投票締切後）
