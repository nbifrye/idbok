# OpenID Foundation Ecosystem Support CG 活動レポート (2025年11月)

> 執筆日: 2026-04-24（遡及執筆）

## 1. 概要

**Ecosystem Support CG (ESCG)** は、OpenID Foundation が展開するエコシステム全体の支援活動を担うコミュニティグループである。Open Banking／オープンファイナンス・デジタルアイデンティティ領域の実装者や規制当局との連携促進、OIDF 加盟組織へのアウトリーチ、各国・地域での OIDF 認定プログラムの普及支援などを主な活動領域とする。仕様策定そのものはスコープ外とし、「Open Banking Reference Technical Architecture and Best Practices」および「Digital Wallet Reference Technical Architecture and Best Practices」などのガイダンス文書整備、エコシステム間の経験共有を主眼とする。共同チェアは Dima Postnikov、Ralph Bragg、Mark Verstege の3名が務め、月次ミーティングを EU 時間帯と Pacific 時間帯で交互に開催している。

2025年11月の ESCG 固有の公開記録（メーリングリストアーカイブ・GitHub）は確認できなかった。ただし、OIDF 全体として11月は重要なマイルストーンが集中した月であり、特に **HAIP 1.0 + OpenID4VP 1.0 / OpenID4VCI 1.0 の大規模インターオペラビリティテスト（11月6〜13日）**と、**HAIP 1.0 Final Specification の会員投票告示（11月24日）**は、ESCG のミッションである「エコシステムオーナーへの実装支援」と直結する動向である。以下、調査した情報源ごとに結果を記録する。

## 2. 公開された仕様・ドラフト改訂

### HAIP 1.0 パブリックレビュー継続（〜12月8日）

**OpenID4VC High Assurance Interoperability Profile (HAIP) 1.0** の Final Specification としての 60 日間パブリックレビュー期間（2025年10月9日〜12月8日）は11月中も継続した。レビュー対象は Draft 05 であったが、11月20日の DCP WG 会議において、最終投票に付す版を **HAIP -06 リビジョン**に更新することが合意された。

11月24日、OpenID Foundation は HAIP 1.0 Final Specification の**会員投票開始を12月9日から23日に実施する**と告示した。HAIP は EU デジタルアイデンティティウォレット（EUDIW）および世界38以上の法域が参照する中核的なインターオペラビリティプロファイルであり、その Final 化は ESCG が支援する多様なエコシステムに直接的な意義を持つ。

## 3. ミーティングおよびメーリングリスト・GitHub 上の公開記録

### ミーティング

ESCG は月次ミーティングを概ね4週間ごとに EU 時間帯（月曜 18:00 Sydney / 9:00 UK）と Pacific 時間帯で交互に開催している。2025年7月28日の初回 EU コールを起点とした4週間サイクルを辿ると、11月は **11月17日（月曜）**前後に定例コールが開催されたと推定される。ただし議事録は non-public であるため内容は確認できない。

確認されている標準アジェンダ項目（2025年9月のメーリングリスト投稿より）:

1. 新参加者の紹介
2. CG 管理業務
3. イベント情報
4. エコシステム更新情報
5. OIDF メンバーシップリマインダー
6. 一般ディスカッション（アクション・チャーターレビュー・Digital Wallet Reference Technical Architecture・バックログ）
7. AOB（その他事項）

11月の定例ミーティングでは、11月6〜13日に実施されたインターオペラビリティテストの結果報告や、12月以降の EUDIW 関連イベント（12月10〜12日の EUDI Wallets Launchpad 2025）に向けた準備が議題に上がったと推定される。

### メーリングリスト

公開アーカイブ（https://lists.openid.net/pipermail/openid-ecosystem-support/）のインデックスには **2025年9月第5週（Week of Monday 29 September 2025）以降の公開エントリが存在せず**、2025年10月・11月分に該当する投稿は公開アーカイブ上に載っていない。

このメーリングリストは「private list」であり、メンバー以外にはメンバーリストが公開されない旨が listinfo ページに明記されている。実質的な議論はミーティング内で行われていると考えられる。

### GitHub

GitHub リポジトリ（https://github.com/openid/cg-ecosystem-support）は 2025年1月2日に作成されたが、2025年11月時点においてもコンテンツは追加されておらず、Issue・Pull Request ともに 0 件のままである。

## 4. 関連イベント

### HAIP 1.0 インターオペラビリティテスト（11月6〜13日）

DCP WG が主導する形で、**HAIP 1.0 Draft 05 + OpenID4VP 1.0 Final / OpenID4VCI 1.0 Final を対象とした大規模インターオペラビリティテスト**が2025年11月6日から13日にかけて実施された。2025年を通じて行われた計11回のインターオップイベントのうち、本イベントは仕様の Final 化直前の最終検証として位置づけられた。

テスト結果の主要指標は以下の通り:

| 組み合わせ               | テスト対数 | 合格率 |
| ------------------------ | ---------- | ------ |
| OpenID4VP 1.0 + HAIP 1.0 | 44 ペア    | 98%    |
| OpenID4VCI 1.0           | 22 ペア    | 82%    |

OpenID4VP + HAIP のテストでは Digital Credentials API を経由するトランザクションが過半を占めた。OpenID4VCI では22ペアのうち11ペアが HAIP モードでテストされ、10ペアが合格した。

参加実装者には **Mattr、Bundesdruckerei GmbH、Google Wallet、Panasonic Connect、MyMahi、Meeco** が含まれた。ESCG が支援する各国・地域のエコシステムオーナーにとって、これらの結果は採用判断の重要な根拠となるものである。

## 5. 今後の予定（2025年11月末時点）

2025年11月末時点で予定されていた主要動向は以下の通り:

- **12月8日**: HAIP 1.0 Final Specification パブリックレビュー期限
- **12月9〜23日**: HAIP 1.0 Final Specification 会員投票
- **12月10〜12日**: EUDI Wallets Launchpad 2025（欧州委員会主催、ブリュッセル）
- **ESCG 定例ミーティング**: 12月も EU・Pacific コールを交互に継続予定
- **Digital Wallet Reference Technical Architecture** 文書のさらなる整備
