# OpenID Foundation Ecosystem Support CG 活動レポート (2025年12月)

> 執筆日: 2026-04-21（遡及執筆）

## 1. 概要

**Ecosystem Support CG (ESCG)** は、OpenID Foundation が展開するエコシステム全体の支援活動を担うコミュニティグループである。Open Banking／オープンファイナンス・デジタルアイデンティティ領域の実装者や規制当局との連携促進、OIDF 加盟組織へのアウトリーチ、各国・地域での OIDF 認定プログラムの普及支援などを主な活動領域とする。仕様策定そのものはスコープ外とし、「Open Banking Reference Technical Architecture and Best Practices」および「Digital Wallet Reference Technical Architecture and Best Practices」などのガイダンス文書整備、エコシステム間の経験共有を主眼とする。共同チェアは Dima Postnikov、Ralph Bragg、Mark Verstege の3名が務め、月次ミーティングを EU 時間帯と Pacific 時間帯で交互に開催している。

2025年12月の ESCG 固有の公開記録（メーリングリストアーカイブ・GitHub）は確認できなかった。ただし、OIDF 全体として12月は重要なマイルストーンが集中した月であり、特に**EUDI Wallets Launchpad 2025（12月10〜12日、ブリュッセル）における EUDIW リソースハブの公開**と、**OpenID4VP 1.0 / OpenID4VCI 1.0 / HAIP 1.0 自己認証プログラムの告知（12月18日）**は、ESCG のミッションである「エコシステムオーナーへの実装支援」と直接的に連動するものである。以下、調査した情報源ごとに結果を記録する。

## 2. 公開された仕様・ドラフト改訂

### Authorization API 1.0 Final Specification 投票開始（12月9日）

2025年12月9日、OpenID Foundation は **Authorization API 1.0 Final Specification** の承認投票開始を通知した（投票期間: 12月23日〜2026年1月6日）。同投票はその後2026年1月12日に Approve 81票・Object 1票・Abstain 25票という大差で承認され、定足数75票を超過した。

Authorization API 1.0 は AuthZEN WG が策定した仕様で、ポリシー実施ポイント（PEP）と認可決定ポイント（PDP）の間を標準化されたプロトコルで接続するものである。エコシステム横断の認可基盤として、ESCG が支援する多様なオープンデータエコシステムにとって基盤技術となりうる仕様である。パブリックレビュー期間（2025年10月23日〜12月22日）は12月中も継続しており、ESCG 参加者がフィードバックを提供していた可能性がある。

### OpenID4VP / OpenID4VCI / HAIP 自己認証プログラム告知（12月18日）

2025年12月18日、OpenID Foundation は **2026年2月26日に自己認証（Self-Certification）プログラムを開始する**と正式発表した。対象仕様は以下の3つ:

| 仕様                                                   | バージョン |
| ------------------------------------------------------ | ---------- |
| OpenID for Verifiable Presentations (OpenID4VP)        | 1.0 Final  |
| OpenID for Verifiable Credential Issuance (OpenID4VCI) | 1.0 Final  |
| High Assurance Interoperability Profile (HAIP)         | 1.0 Final  |

テストツールはオープンソースで無償提供され、OIDF サーバーまたはローカル環境で実行可能。実装者は自己認証ログを OIDF に任意提出することで、openid.net/certification 上への結果公開が得られる。2025年を通じて11回の相互運用テストイベントが実施され、最終仕様の品質が検証されていた。ESCG が支援する38以上の法域での OIDF 仕様採用推進にとって、適合試験基盤の整備は直接的な意義を持つ。

## 3. ミーティングおよびメーリングリスト・GitHub 上の公開記録

### ミーティング

ESCG は月次ミーティングを概ね4週間ごとに EU 時間帯（月曜 18:00 Sydney 時間 / 9:00 UK 時間）と Pacific 時間帯（金曜 10:00 Sydney 時間）で交互に開催している。2025年7月28日の EU コールを起点とした4週間サイクルを辿ると、12月は **12月15日（月曜、Pacific 寄りの時間帯）**前後に定例コールが開催されたと推定される。ただし議事録は non-public であるため内容は確認できない。

確認されている標準アジェンダ項目（2025年9月のメーリングリスト投稿より）:

1. 新参加者の紹介
2. CG 管理業務
3. イベント情報
4. エコシステム更新情報
5. OIDF メンバーシップリマインダー
6. 一般ディスカッション（アクション・チャーターレビュー・Digital Wallet Reference Technical Architecture・バックログ）
7. AOB（その他事項）

12月の定例ミーティングでは、EUDI Wallets Launchpad 2025 で発表された EUDIW リソースハブや自己認証プログラムの告知に関する情報共有が議題に上がったと推定される。

### メーリングリスト

公開アーカイブ（https://lists.openid.net/pipermail/openid-ecosystem-support/）の月次インデックスを確認したところ、2025年12月分のアーカイブページは **404 エラーとなり存在しない**。確認できた最新のアーカイブは 2025年9月（Week of Monday 29 September 2025）であり、10月以降の投稿は公開アーカイブに存在しない。

このメーリングリストは「private list」であり、メンバー以外にはメンバーリストが公開されない旨が listinfo ページに明記されている。実質的な議論はミーティング内で行われていると考えられる。

### GitHub

GitHub リポジトリ（https://github.com/openid/cg-ecosystem-support）は 2025年1月2日に作成されたが、2025年12月時点においてもコンテンツは追加されておらず、Issue・Pull Request ともに 0 件のままである。

## 4. 関連イベント

### EUDI Wallets Launchpad 2025（12月10〜12日、ブリュッセル）

欧州委員会が主催する **EUDI Wallets Launchpad 2025** が2025年12月10〜12日にブリュッセルで開催された。OpenID Foundation は Executive Director Gail Hodges と Technical Director Mark Haine が登壇し、以下のセッションを担当した:

- **「Outlook of Wallet Technical Specifications」**（Gail Hodges）: OIDF が EU に提供する仕様群の概要、ISO・ETSI 等の国際標準化機関との協調状況
- **「Wallet Conformance Test Plan」**（Mark Haine）: EUDI ウォレット向け機能的適合試験のアプローチと OIDF のテスト成果物

### EUDIW リソースハブの公開（12月11日）

Launchpad 2025 のタイミングで、OpenID Foundation は **EU デジタルアイデンティティウォレット（EUDIW）実装者向けリソースハブ**を公開した。同ハブは ESCG のミッションである「エコシステムオーナーへの実装支援」の一環として位置づけられており、EU（eIDAS 2.0）をはじめ38の法域での OIDF 仕様採用を促進するため、技術ガイダンス・規格文書・テストツールへのアクセスを一元化する。

リソースハブでは ESCG が開発中の **「Digital Wallet Reference Technical Architecture and Best Practices」**文書も参照資料として位置づけられており、EU との相互運用性を求める非 EU 法域の実装者に対しても資産として提供される。

### OIDF 理事会選挙の選挙告示（12月初旬）

2025年12月1日時点で、2026年度 OIDF 理事会の企業代表1席・コミュニティ代表2席が改選対象として告示されていた。ESCG 共同チェアの **Mark Verstege** が企業代表として改選に臨み、2026年1月13日に再選が確定している。

## 5. 今後の予定（2025年12月末時点）

2025年12月末時点で予定されていた主要動向は以下の通り:

- **2026年1月6日**: Authorization API 1.0 Final Specification 投票期限
- **2026年2月26日**: OpenID4VP 1.0 / OpenID4VCI 1.0 / HAIP 1.0 自己認証プログラム開始
- **2026年Q2**: OIDF 独立認定サービス（Accreditation Services）パイロット開始（MOU 締結5機関との協業）
- **ESCG 定例ミーティング継続**: 2026年1月以降も EU・Pacific コールを交互開催
- **Digital Wallet Reference Technical Architecture** 文書のさらなる整備
