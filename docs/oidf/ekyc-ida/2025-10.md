# OpenID Foundation eKYC-IDA WG 活動レポート (2025年10月)

> 執筆日: 2026-04-25（遡及執筆）

## 1. 概要

eKYC & Identity Assurance Working Group（以下「eKYC-IDA WG」）は、本人確認済みクレーム（verified claims）と検証プロセスに関する情報をどのように OpenID Connect 上で伝達するかを標準化する OpenID Foundation の WG である。中核仕様は **OpenID Connect for Identity Assurance 1.0 (OIDC4IDA)**、**OpenID Identity Assurance Schema Definition 1.0**、**OpenID Connect for Identity Assurance Claims Registration 1.0** の3点で、いずれも Final Specification。共同議長は Mark Haine、Naohiro Fujie、Hodari McClain の3名。

2025年10月の eKYC-IDA WG は、**Final 化済みの OIDC4IDA に対する Errata Set 1 の取り込み作業** と、**Authority（権限／委任関係）の拡張仕様化** が並行して進行した月であった。ML への投稿は全5通（うちアジェンダ2通、Notes & Recordings Policy 通達1通、10月29日コールのキャンセル通知2通）と低ボリュームだったが、アジェンダメールに含まれた議題項目から、Errata PR #263〜#265、Authority 関連 Issue #1470〜#1473、Conformance Issue #1437/#1469、UK 政府・NCCOE/NIST とのプロファイル対話など、実質的な進行内容が把握できる。

定例会は水曜 UTC 開催で、10月は **10月8日・10月15日に開催記録あり**、10月29日は IIW 41 直後のタイミングで **キャンセル** された。10月22日は IIW 41 期間中でアジェンダメールが確認できない。

## 2. 公開された仕様・ドラフト改訂

### OIDC4IDA Errata Set 1 取り込み作業の継続

OpenID Connect for Identity Assurance 1.0 は2024年10月1日に Final Specification として公開済み。10月時点では、Final 化後に蓄積された errata を取り込む **Draft 17 incorporating errata set 1** への作業が進行中であった（Final 公開から1年が経過し、初の errata 取り込み版を準備する節目）。10月8日・15日のアジェンダにある以下の PR/Issue が errata 取り込みの骨格を成す:

- **PR #263** (Issue #1476 対応): IDA 仕様の規範的参照日付を最新化
- **PR #264** (Issue #1471 対応): 法人クレーム一覧の削減
- **PR #265** (Issue #1454 対応): `check_details` の内容明確化
- **Issue #1474**: eKYC-IDA & Schema に関する **ISO 改訂リクエスト**

10月末時点では errata set 1 取り込み版はまだ公開投票に至っておらず、作業継続中。（Draft 17 の最終公開は2026年に入ってから。遡及執筆時点の補足）

### Authority / Claims 拡張の進行

Authority extension（当局／組織／代理権限を OIDC4IDA で表現する拡張）の議論が10月中の最大の技術テーマ。10月15日アジェンダに挙がった中核 Issue:

- **Issue #1470**: 法人と個人との関係性の取り扱い
- **Issue #1471**: 法人向けクレーム一覧の削減（PR #264 で対応）
- **Issue #1472**: **AI エージェントが委任を受ける場合** の記述方法（新しいユースケース）
- **Issue #1473**: Authority / Delegation / Relationship に関する**ユースケースリスト** の作成

特に Issue #1472 は、AI エージェントの台頭を受けて「エージェントが人間の代理として委任を受けたとき、それをどう OIDC4IDA / Authority 拡張で表現するか」という問いであり、AIIM CG（AI Identity Management CG）とのプレゼンテーション連携も進行中であった。

### その他の作業仕様

- **OpenID Connect Advanced Syntax for Claims (ASC) 1.0**: ドラフト継続
- **OpenID Attachments 1.0**: ドラフト継続
- **Taxonomy サブグループ**: 新規チャーター検討中（10月15日アジェンダ）

### Notes & Recordings Policy の適用

10月9日 13:48 UTC、Mike Leszcz から全 WG/CG 共通で [New OpenID Foundation Notes & Recordings Policy](https://lists.openid.net/pipermail/openid-specs-ekyc-ida/Week-of-Mon-20251006/000974.html) が通達された。AI 文字起こしボット・自動文字起こしサービスの参加禁止を規定する OIDF 横断の運営変更であり、eKYC-IDA を含む全 WG/CG で10月9日以降の定例会に適用された。

## 5. GitHub 上の議論

eKYC-IDA WG の仕様リポジトリは [openid/ekyc-ida (GitHub)](https://github.com/openid/ekyc-ida) と [Bitbucket: openid/ekyc-ida](https://bitbucket.org/openid/ekyc-ida/) の両方に存在し、議事録・Issue・PR は Bitbucket を正として運用されている。Bitbucket Cloud Issues/Wiki は2026年8月20日に Atlassian により削除予定で、移行計画は継続検討中。

10月のアジェンダから推定される主要 Issue/PR の議論状況:

### IDA Errata 関連

- **PR #264** (Issue #1471): 法人クレーム一覧削減

### Conformance / Profiles 関連

## 6. 関連イベント

### FIDO Authenticate（2025年10月13〜16日、Carlsbad）

FIDO Alliance 主催のイベント。10月8日アジェンダで外部イベントとして言及された。eKYC-IDA WG からの公式セッションは確認できないが、認証／本人確認の隣接領域として情報共有対象。

### OIDF Cisco Workshops（2025年10月20日）

OpenID Foundation が Cisco と共催したワークショップ。eKYC-IDA の議題に言及あり。

### IIW 41（2025年10月21〜23日、Mountain View）

Internet Identity Workshop XLI。eKYC-IDA 関連のセッションとして IIW Session 10J「OpenID Connect 4 Identity Assurance」が開催された。eKYC-IDA WG コミュニティメンバーの多くが参加し、翌週10月29日の定例会キャンセルの背景にも関係する。

### IETF 124 Montreal（2025年11月1〜7日）

Financial Data Exchange の年次サミット。金融データ連携領域で IDA が接続する文脈。
