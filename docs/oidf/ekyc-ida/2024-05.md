# OpenID Foundation eKYC-IDA WG 活動レポート (2024年5月)

> 執筆日: 2026-05-21（遡及執筆）
>
> 本記事は 2024 年 5 月の活動を 2026-05-21 時点の視点で遡及的にまとめたものです。

## 1. 概要

eKYC & Identity Assurance Working Group（以下「eKYC-IDA WG」）は、本人確認済みクレーム（verified claims）と検証プロセスのメタデータを OpenID Connect 上で標準的に伝達する仕組みを策定する OpenID Foundation の WG である。中核仕様は **OpenID Connect for Identity Assurance 1.0 (OIDC4IDA)**、**OpenID Identity Assurance Schema Definition 1.0**、**OpenID Connect for Identity Assurance Claims Registration 1.0** の 3 本。

**2024 年 5 月は eKYC-IDA WG にとって、5 年以上を費やしてきた中核 3 仕様の Final 化に向けた "Final Call Issues & PRs" の編集消化を最終段階まで押し進めた月** である。月初の 5/1 コールは Mark Haine の家族の不幸により直前キャンセルとなったが、5/8・5/15・5/22・5/29 の 4 本の定例コール用アジェンダがいずれも `Final Call Issues & PRs` セクションを冒頭に据えた構成で配信され、PR #212/#213/#214/#215/#216/#217 という Final Call 対象 PR 群の連続マージとともに、Hodari McClain・Kosuke Koiwai・Mark Haine の 3 名が editorial 修正の主力として可視化された月でもある。当月の流れを整理すると次のとおり:

- **5 月 1 日コール（直前キャンセル）**: Mark Haine の家族の不幸（"a death in the family"）により Mike Leszcz が 5/1 12:17 UTC に正式キャンセル通知を ML 配信。アジェンダ自体は 11:24 UTC に既に配信済みで、PR #212/#213/#214 の Hodari 担当 3 本セットと Kosuke 担当の Issue #1410/#1411/#1412 が Final Call Issues & PRs として明示列挙されていた
- **5 月 8 日コール（開催）**: 1 週間ぶりの定例復帰。アジェンダで **PR #215（Mark 担当、Issue #1410 = IDA Schema Definition 追加 typo 対応）／ PR #216（Mark 担当、Issue #1411 = IDA Claims 追加 typo 対応）が新規登場** し、Kosuke が Issue として提起していたものを Mark 自身が PR 化した構図が読み取れる
- **5 月 15 日コール（開催）**: PR #217（Kosuke/Mark 担当、Issue #1412 = IDA Core/Claims/Schema 間の参照セクション整理）が新規登場。PR #212-#216 が Final Call Issues & PRs リストから外れ、Final 化前の editorial 修正サイクルが急速に消化されたことを示す
- **5 月 22 日コール（開催）**: Final Call Issues & PRs リストは PR #213（Hodari、Dima feedback 1）と PR #217（Kosuke/Mark、参照セクション）の 2 本にまで圧縮。Attachments の PR #204（ISO formatting）は引き続き継続項目
- **5 月 29 日コール（Identiverse 2024 ハイブリッド開催）**: Aria Conference Center の Bluethorn 8 でハイブリッドコール。Final Call Issues & PRs は PR #213 のみに圧縮、Attachments セクション自体がトップレベルから消え（後の 6 月以降は Identity Assurance 内で継続）、新たに **Authority セクションが「interest noted in draft report」として独立議題化**

共同議長体制は当月時点で **Mark Haine / Naohiro Fujie / Torsten Lodderstedt / Tony Nadalin の 4 名体制**（Hodari McClain の共同議長就任は同年 12 月）。Mark Haine が毎週水曜の WG コール用アジェンダを ML に配信し、WG 運営の実質的なドライバーを務めていた。PR 編集の主力は Hodari McClain（PR #212/#213/#214/#204）／ Kosuke Koiwai（Issue #1410-#1412 提起、PR #217 担当）／ Mark Haine（PR #215/#216 担当）の 3 名構図で、4/22-25 の ML 上の技術議論（"Move transaction specific purpose out of the main specification" スレッド、Axel Nennker / Bjorn Hjelm / George Fletcher 参加）から続く「Final 化前の論点クロージング」のリズムが定着している。

## 5. GitHub 上の議論

eKYC-IDA WG は **GitHub 上にメイン仕様リポジトリを保有していない**。レジストリ上は `https://github.com/openid/ekyc-ida` が記載されているが、2024 年 5 月時点では当該パスは 404 を返し、独立した有意な GitHub 活動はない。WG のメイン作業は [bitbucket.org/openid/ekyc-ida](https://bitbucket.org/openid/ekyc-ida) で行われている。後の 2026 年に立ち上がることになる補助リポジトリ（`openid/eKYC-IDA-Authority` ／ `openid/eKYC-IDA-Registry-Profile`）は 2024 年 5 月時点では存在しない。

Bitbucket Cloud は SPA（JavaScript レンダリング）で HTML を生成するため、WebFetch 経由では Issue / Wiki / Pull Request の本文を取得できない構造的制約がある。本稿では §2・§3・§4 で示したとおり、**ML 上のアジェンダメール（5/1・5/8・5/15・5/22・5/29 の 5 通）に列挙された Issue / PR 番号と短い説明文** を一次情報として再構成し、Bitbucket 直接アクセスを伴わない範囲で WG の議論内容を表現している。

5 月時点で ML から確認できる Bitbucket 側の主要な「動き」は次の 4 群に整理できる:

  - **5 月全期間 Discussion Items 継続**: Issue #1414（Daniel、VC binding）— Public Review 起動スコープから外す判断は 7 月以降の議論で確定
- **Attachments — 独立トップレベルセクションから消失への移行**:

- **Identity Assurance（中核仕様）— Final 化に向けた WG コンセンサス確認**: 5/29 アジェンダで継続課題化されていた「Working group consensus on final OIDF vote proposal remains pending」状態を解消するため、Final Call Issues & PRs リスト圧縮の最終段階（PR #213 マージ → 「NONE!」状態への移行）を 6 月初頭の WG コールで完了させる段取り
- **PR #213**（Hodari、Dima feedback 1 / Issue #1408）: 5 月全期間継続してきた最後の Final Call PR のマージ。6 月初頭のコールで処理予定
- **Issue #1414**（Daniel、VC binding）: 継続論点。Public Review スコープに含めるか外すかの判断を 6 月期間中に確定
- **Attachments — Identity Assurance 内への統合**: 5/29 アジェンダでトップレベルから消失した Attachments セクションの後続扱い。PR #204（ISO formatting）の続報と、Identity Assurance 内での継続議題化
- **Profiles and Registries — 継続議論**: Issue #1390（document type 定義欠落）／ Issue #1339（OIDC4IDA プロファイル）の継続
- **Authority — Implementers Draft 1 へ向けた予備議論**: 5/29 アジェンダで初登場した Authority セクション（draft report への関心）の本格議論開始。後の 6 月期間で age-appropriate internet / parental delegation authority / EUDI LSPs の legal entity / age 関連考察として展開されることになる
- **EIC 2024**（European Identity and Cloud Conference 2024、6/4-7 Berlin）: OpenID Foundation 関係者が登壇予定。EUDI Wallet Architecture and Reference Framework（ARF）周辺の議論を eKYC-IDA WG の Authority 仕様に取り込むための知見交換が見込まれる
