# OpenID Foundation eKYC & IDA WG 活動レポート (2025年11月)

> **執筆日**: 2026-04-24（遡及執筆）
>
> 本記事は 2025年11月の活動を 2026-04-24 時点の視点で遡及的にまとめたものです。

## 1. 概要

**eKYC & Identity Assurance WG (eKYC-IDA WG)** は、OpenID Connect を拡張して本人確認済みクレームの標準的な伝達方法を定義する Working Group である。WG 議長は Mark Haine、Naohiro Fujie、Hodari McClain。毎週水曜 15:00 UTC に定例コールを開催し、成果物のホスティングには Bitbucket (`https://bitbucket.org/openid/ekyc-ida`) を利用している。

2025年11月は定例コール 4 回のうち **2 回が中止**（11月5日: 参加者不足、11月12日: 定足数不足）となり、**2 回が開催**（11月19日・11月26日）された。活動密度という点では比較的静かな月だが、以下の取り組みが継続・進展した。

1. **Identity Assurance Errata の ISO PAS 化対応**: Bitbucket 上で PRs #266〜#274 が整備され、OpenID Connect for Identity Assurance 1.0 および OpenID Identity Assurance Schema Definition 1.0 を ISO/IEC PAS フォーマットへ適合させる編集的変更が進んだ
2. **Issue #1500・#1501 の継続審議**: 添付ファイルの位置づけ（#1500）および住所例示への `country_code` 追加（#1501）が引き続き議論されていた
3. **Authority & Delegation（委任権限）仕様の議論**: 法人と個人の関係、AI エージェントへの委任といったユースケースの整理が継続された
4. **AIIM（AI Identity Management CG）との連携**: 分類体系（タクソノミー）サブグループのチャーターと GitHub リポジトリが整備された

## 2. 公開された仕様・ドラフト改訂

11月中に新たな仕様の公式公開やパブリックレビューの開始はなかった。

2025年10月22日に Bitbucket で公開された **OpenID Connect for Identity Assurance 1.0 Draft 17 incorporating Errata Set 1** が継続的に参照されており、WG はこの Errata Set 1 を ISO/IEC PAS 化するための編集整理（PRs #266〜#274）を 11月中に本格着手した。

**各種ドラフトの状況（2025年11月末時点）**

| 仕様                                                         | 状況                                         |
| ------------------------------------------------------------ | -------------------------------------------- |
| OpenID Connect for Identity Assurance 1.0 Errata Set 1       | ISO PAS 向け編集整理作業中（PRs #266〜#274） |
| OpenID Identity Assurance Schema Definition 1.0 Errata Set 1 | 同上                                         |
| OpenID Connect Advanced Syntax for Claims (ASC) 1.0          | Implementer's Draft 1 推薦に向けた内部調整中 |
| OpenID Attachments 1.0                                       | 2025年6月に Final Specification 承認済み     |
| Authority Claims Extension（委任権限）                       | ユースケース整理・初期ドラフト作成段階       |

### 2025-11-05 定例コール（中止）

Mark Haine が参加者不足を理由に中止を通知した（メッセージ 000978）。通知には 10月15日付の議題メールが参照されており、当初予定されていた議題は以下の通りだった。

- **Authority**: タクソノミー作業、委任・関係性に関するユースケース、法人と個人の関係
- **Identity Assurance — Errata**: 仕様の明確化と規範的参照更新を目的とした PR 2 件
- **Conformance & Certification**: 適合性プロファイルの策定、ネガティブテスト手順
- **Profiles & Registries**: スキーマ定義・仕様プロファイリング、英国政府および NIST/NCCoE との協議（Pending）

なお参照議題には、前月のイベントとして FIDO Authenticate（10月13〜16日）、IIW Fall 2025（10月21〜23日）、IETF 124 モントリオール（11月1〜7日）が記載されていた。

### 2025-11-12 定例コール（定足数不足）

Hodari McClain が定足数不足を通知した（メッセージ 000980）。この会合では **提案されている ISO 改訂に対する内部 2 週間レビュー期間のスキップ可否について投票**する予定だったが、それを次週（11月19日）に持ち越すことになった。

Hodari McClain が送付した議題メール（メッセージ 000979）には以下が含まれていた。

**Member Reminders（OIDF 全体からの通知）**:

- OpenID4VC High Assurance Interoperability Profile (HAIP) 1.0: パブリックレビュー終了（12月8日）・投票開始（12月9日）
- Authorization API 1.0 Final Specification: パブリックレビュー終了（12月22日）・投票開始（12月23日）
- 2026 年 OIDF 理事選挙: 12月8日〜2026年1月12日

**主要議題**:

- **Authority & Delegation**: タクソノミーサブグループ作業、委任関係のユースケース、AI エージェントへの委任シナリオ
- **Identity Assurance — Errata**: 仕様明確化および規範的参照更新の PR
- **Conformance & Certification**: 最終適合性プロファイルの策定、ネガティブテスト
- **Profiles & Registries**: OIDC4IDA プロファイル作成、英国政府および NCCOE/NIST との協議（Pending）

### 2025-11-19 定例コール（開催）

Mark Haine が議題を送付（メッセージ 000981）。この会合が事実上 11月の最初の実質的な議論の場となった。

**主要議題**:

- **Identity Assurance — Errata（ISO PAS 対応）**: 規範的参照、ISO 編集修正、抄録（Abstract）削除、謝辞（Acknowledgments）削除、表記規則（Notational Conventions）削除等に対応する **9 件の PR** のレビュー
- **Issue #1500**: 添付ファイルの位置づけ（attachment locations）の明確化が必要
- **Issue #1501**: 住所の例示に `country_code` フィールドが欠如している問題（継続）
- **Authority & Delegation**: 委任権限に関するユースケース（法人と個人の権限関係、AI エージェントへの委任）
- **AIIM（AI Identity Management CG）**: タクソノミーサブグループのチャーターと GitHub リポジトリの整備
- **Conformance & Certification**: 最終適合性プロファイルとネガティブテストフレームワークの開発

また、2026年Q1の国際会議スケジュールとして ISO/IEC JTC 1/SC 27 会議（ニュルンベルク、3月9〜17日）と IETF 125（深圳、3月14〜20日）が確認された。

### 2025-11-26 定例コール（開催）

**主要議題**:

## 5. Bitbucket 上の議論

eKYC-IDA WG の成果物は主に **Bitbucket** (`https://bitbucket.org/openid/ekyc-ida`) で管理されている。

### ISO PAS 向け編集的 PR 群（PRs #266〜#274）

11月後半の議題メール（000981・000982）で言及された一連の PR 群。いずれも Hodari McClain による、OpenID Connect for Identity Assurance 1.0 および OpenID Identity Assurance Schema Definition 1.0 を ISO/IEC PAS フォーマットに適合させるための編集整理を目的とする。

11月19日時点では「9 件の PR」として総括されており、11月26日の議題で初めて PR 番号 #266〜#273（および #274）が明示的に参照された。

| PR#        | 内容（概要）                                                      |
| ---------- | ----------------------------------------------------------------- |
| #266〜#273 | 規範的参照の更新、抄録・謝辞・表記規則の削除等の ISO PAS 編集修正 |
| #274       | 添付ファイルに関する文言の明確化（Issue #1500 対応）              |

これらの PR は翌12月中のレビューを経て、2026年1月初旬にマージされた。

### Issue #1500 — 添付ファイルの位置づけの明確化

11月19日の議題で初めて明示された Issue。仕様における添付ファイル（attachments）の取り扱い位置づけに関する文言が曖昧であることが指摘され、PR#274 によって対応が図られた。

### Issue #1501 — 住所例示における `country_code` の欠如

Errata Set 1 の継続的な論点。住所クレームの JSON 例示に `country_code` フィールドが含まれていない問題で、11月19日・26日の両コールで引き続き審議された。12月にも持ち越しとなった。

11月5日の（中止された）議題に記載されていた。IETF 124 では OAuth WG や GNAP 等のアイデンティティ関連 WG の会合が行われており、eKYC-IDA WG と関連する標準化動向の把握の場として認識されていた。

11月12日の議題（Hodari McClain）で、OIDF 全体に向けた理事選挙スケジュールが周知された。

11月19日の議題で確認された。

- **ISO/IEC JTC 1/SC 27 WG 会議**: ニュルンベルク、ドイツ（2026年3月9〜13日・16〜17日）
